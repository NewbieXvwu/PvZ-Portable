### 真根因（比原先的猜测更准确）

**不是**"WSL 空闲 60 秒关机"这么笼统 —— 实测是：
**本机 Agent 两次 SSH 调用之间的空档里，WSL 会关机；下一条命令再把它唤醒。**
证据：`ps -o pid,lstart -p 1` 显示 **PID 1 的启动时间是 15:05:04**（不是我 12:32 连上时那次），
说明中间已经重启过多次。**tmux server 跟着 WSL 一起死 → codex 被杀，且不留 EXIT 行。**

**→ 这解释了所有"codex 跑一分钟就没了"的现象**（12:40、00:16 都是同一机制）。

### 修法（已完成）

- **旧 keeper 确认是死的**：`LastRunTime = 2026/10/8 16:58:39`、`LastTaskResult = 0x40010004`、
  **`NextRunTime` 为空** → 它从 10-08 起就没再跑过。
- **新任务**：
  ```
  schtasks /create /tn PvZWSLKeeper /tr "wsl.exe -d Ubuntu -e sleep 290" /sc minute /mo 5 /f
  ```
  再设 `MultipleInstances=Parallel`、`DisallowStartIfOnBatteries=False`、
  `StopIfGoingOnBatteries=False`、`StartWhenAvailable=True`、`ExecutionTimeLimit=PT1H`。
  **每 5 分钟起一个 `sleep 290` 持续占住 WSL**（290 < 300 且允许并行 → 没有空窗）。
- **踩过的坑**：
  - `Register-ScheduledTask` + `New-ScheduledTaskSettingsSet` 那版**静默失败**（任务被删了没建回来）
    → 改用 `schtasks` 才成功。**以后改计划任务先用 schtasks，再用 `Set-ScheduledTask` 调细节。**
  - `$t.Settings.AllowStartIfOnBatteries` **不是**真实属性名（真实的是 `DisallowStartIfOnBatteries`），
    赋值会静默无效。
  - **多层引号必炸** → 用 `powershell.exe -NoProfile -EncodedCommand <base64(UTF-16LE)>`

### 踩过的 5 个坑（都会静默或卡死）

1. **pip 镜像源 403**：`~/.venvs/ml` 的 pip 配了 `mirrors.bfsu.edu.cn`，装 `mcp` 直接 403。
   → 用 `--index-url https://pypi.org/simple` 才行。
2. **npm 11 默认跳过 install script**：`node-pty`/`koffi`/`@deepseek-ai/dsh-subprocess-local` 的
   安装脚本被跳过。→ `npm config set allow-scripts=... --location=user` 后重装。
   （不过实测 dsh 能跑，`node-pty` 有 `prebuilds/linux-x64`。）
3. **`dsh plugin add` 建出来的 profile 少了 `@deepseek-ai/dsh-headless`** →
   **dsh 会启 web 应用并永久卡住（0 字节输出、`do_epoll_wait`、无网络连接）**。
   → 必须手工把 `@deepseek-ai/dsh-headless` 加进 `package.json` 的 `dsh.profile.bundles`。
   **注意 `dsh plugin add @deepseek-ai/dsh-headless` 会失败**（npm 上那个包是 0.0.1-rc.1，与 0.2.0-rc.2 peer 不兼容）
   —— 它其实**由 dsh 运行时自带**（`<npm root -g>/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-headless`），
   **只需写进 bundles 数组，不用装**。
4. **`.credentials.yaml` 必须 600**，否则 `credentials-local` 插件报错（`readable beyond its owner`）。
5. **bundle 里是绝对路径**，换机器必须改 `command`/`cwd`/`env`。
   我改的是**部署副本** `$DSH_HOME/profiles/pvz-teacher/node_modules/@local/pvz-teacher/cordis.patch.yml`
   （**没动仓库里的 `bundle/cordis.patch.yml`** —— 已核实 git status 干净）。
