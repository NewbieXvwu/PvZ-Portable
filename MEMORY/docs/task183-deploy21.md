## 序贯方法与终点

固定四个查看点：各冒险任务完成其上限的 1/4、1/2、3/4、全量（向上取整）。
每次仍覆盖五种地形。留出两格在首批各跑满 96 种子，始终只监控；下降 ≥20pp 记 WARNING。
冒险上限不变，仍是 1728 个三方种子，另有 192 个留出种子；全量共 5760 局。

终点在开评前冻结：低胜率任务用 `final_wave / wave_count`（赢局计 1），其余用胜负。
下一轮低胜率标记依据本轮现任胜率 ≤20%；初始包括 task180 指出的 L33/L34/L39/L40/L41/L46。
屋顶继续沿用 v6 的原始存活波数 Wilcoxon 否决。混合终点总体差单位为归一化分数，
3pp 对应分数 0.03；结果另保留纯胜率差，避免与旧门禁混淆。

总体使用配对分数差的正态近似区间，样本方差下限为 1/n（避免全相同对产生零宽区间）。
显著性预算等分给四次查看及两个候选：每次每臂 `alpha=.05/8`，区间为双侧
`1-alpha`；要求下界 >−0.03 且点估计 ≥0。总体近似依赖批量样本的 CLT，不宣称有限样本精确性。

分地形保留四个非屋顶地形 Holm 家族（总 alpha .05）与独立屋顶家族（总 alpha .01），
分别再除以 8，避免重复查看扩大否决概率。普通终点用原有单侧精确 McNemar；
含低胜率终点的非屋顶地形改用同一配对分数差的单侧精确 Wilcoxon，Holm 规则不变。
屋顶仍用原始波数的单侧精确 Wilcoxon、丢零、并列平均秩。

某臂满足晋升条件即为通过；区间上界 <0 或触发地形否决为明确否决。
两个臂在同一次查看均有明确结论时才停止；任何一臂未定，三方共同继续，
A−B 从不使用不同长度的样本。到上限仍未通过则否决；最后选通过臂中总体点估计最高者。
相同点估计按 A/B 固定次序打破平局。重复查看开销只读当前少量对局记录、做配对统计，
不跑旧档案重放；引擎只补未完成种子。
