## 与 task74 旧批次的差异

task74（台式机，round 11 学生，旧 `human` 口径，各 16 局）在用户磁力寒冰卡组上是 L36 16/16、L37 15/16、L38 16/16、L39 0/16。本批 L36（29/32 与 16/16 差 p=0.54）与 L38（32/32 对 16/16）复现了旧批，**L37 掉到 0/32**（对 15/16，p<1e-8）。这是本任务唯一一处批次不一致，做了三组对照来定位（`scripts/task79_control.py`，清单只落 `artifacts/`，不登记任务族）：

| 对照 | 设计 | 结果 |
|---|---|---|
| A | task74 自己的 16 个种子（30560–30575），本批学生与口径 | 4/16 |
| B | 本批 16 个种子（79020000–15），改回旧 `human` 口径 | 4/16（配对：human 4、human_v2 0，McNemar p=0.125） |
| C | L36 本批 8 个种子，旧 `human` 口径（正对照） | 7/8 |
| D | 同 A 的种子，换本机较新的 dw5i_s1（a106d1a7…） | 0/16，且退化 |

A 说明**不是种子块**：同样的 16 个种子，task74 的 15/16 在本批只有 4/16。B 与 C 说明**不是观测口径**：L36 在旧口径下 7/8（与本批 29/32 一致），L37 换回旧口径仍是 4/16。D 不能当学生能力对照：dw5i_s1 在本栈下退化到每局只种 4 株（2 蘑菇 + 1 睡莲 + 1 缠绕）、0 次老师推翻、第 6–9 波就被破防，说明它作为 proposal policy 与现行观测/叶值不兼容，**不能用它推学生强弱**。

剩下的变量是 round 11 与 dw4i_s1 的差距，以及引擎构建（台式机 cq/build4 16989f23… 对 Mac 1b3d307f…）。本机没有 round 11 的同摘要副本（SSH 中断），两机引擎也无法逐位对照，所以这两项**不能分离**。能说的是描述性证据指向学生：按阳光菇密度，r11 在 task74 的 L36/L37 都是 **1.96 株/波**，dw4i_s1 在本批是 0.99–1.63 株/波（L37 magnet 最低 0.99，A 对照 1.10），20 波关够用、30 波关不够——这与 task67b "老师兜不住学生的小差距" 的方向一致，但不是因果证明。

## 建议

**可直接进 qc（老师 ≥ 50%）**

- **L36**：两套都过线，首选 `split`（31/32，96.9%），`magnet`（29/32，90.6%）可作同族备选；两者统计上等效，选哪套不影响准入。
- **L38**：首选 `magnet`（32/32，100%）；`tall`（23/32，71.9%）虽过线但显著更差（p=0.0020），只在磁力菇与其它关冲突时用。

**需要用户示范（老师 < 50%）**

- **L37**：推荐 `split`（12/32，37.5%，上界 54.7%）。`magnet` 0/32 应淘汰。注意这一关的落差主要是学生续航（见上节），若主控把 round 11 或更强的学生放上 Mac，可能不需要示范就能过线——task74 用 r11 在同 16 个种子上是 15/16。先决定学生再决定是否要示范，比先做示范更省。
- **L39**：推荐 `blover`（8/32，25%，对 `cactus` p=0.0048）。气球是这关的硬约束：旧批次用户卡组（无对空）0/16、13 局气球破防，本批仙人掌 18/32 气球破防、三叶草降到 6/24。即便换三叶草也只到 25%，示范是必要的。

**不改的**：τ=0.925 与 `human_v2` 口径不动（上一节）；旧任务族与旧雾族不动；生产默认不动。复现入口 `scripts/task79_fog36.py`（traces/opacity/cold/report）与 `scripts/task79_control.py`（对照）。
