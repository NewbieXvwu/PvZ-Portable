1. **倍率档**（照 task75b 规则：老师胜率 ≥50% 的最高档作为起始档）：
   - `day_l7_train_rand`：1.0 倍 53%（Wilson 下界 36%）已过线，**直接按 1.0 登记**，不需要低倍档。
   - `night_l12_train_rand`（16%）与 `pool_l21_train_rand`（22%）在 1.0 倍不过线。原方案为先扫0.5/0.75两档（各16局）；Mac task93b已完成扫描与扩采，见下一节：泳池建议0.5倍，夜间0.5倍仍<50%，暂缓接入（照task75b L30先例）。原1.0倍任务及144局验证均保持冻结。
2. **采样占比**：与旧扰动冻结数据同量级起步——legacy d7p/d8p/d9p/d10p 行占比在 r14 报告中为 4.31%，在本实验 A 基线中为 4.48%。建议三族合计从 **~4% 行占比**起步；每族每轮 48 局可作为滚动采集单元，但必须按实际保留行数核对达标情况。`label_weight 1.0` 平权起步，使本次实验主要考察新增覆盖，不同时调整权重。task84 B 的 65/192 不能单独证明加权的因果效果：实际 resolved recipe 为 380 标签、扰动权重 1.5，而 A 为 348 标签、扰动默认权重 1.0，语料与权重同时变化；旧稿所述“0.5→1.5、3倍”与配置不符。
3. **对 heldout 的预测**：新数据每个种子都是新卡组，卷心菜(32) 等稀有卡从"一份冻结快照"变成"每局都在见"，期望 heldout 均值从抽签区（124–169）回到典型簇（166–169）或以上，且**训练种子间的方差缩小**（不再依赖单一快照的运气）；对照 `day_l7_eval_d7`（标准卡组）应持平。可证伪判据见下节。

**后续采集预算与收据**：在本实验冻结A语料的规模、且保留行密度近似当前144局时，三族新数据合计约需70.8万行、总计约3455局（含已有144局）才接近4%。这是预算估计，生产语料增长或卡组差异都会改变换算，必须按实际行数复核。当前验证仍固定144局，不临时扩量或提权。后续扩量须另行预登记独立新种子段，扫描全仓与种子账本防撞，逐种子取得引擎校验收据，并保留已有任务定义和收据；不能复采旧48局冒充新覆盖。若候选池或卡组约束改变，按AGENTS §8另开族并登记DESIGN。
