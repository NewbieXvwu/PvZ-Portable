### 4. 数据与课程建议，以及验收口径

**先做同预算的1.0倍开局专项。** 保持记分板现有卡组与`human_v2`观测，八关各采集至少一个24局组，L29/L32/L37各加一个组，合计264局新训练种子。八关专项占用同一轮原有采集预算，优先替换L7重复采集份额，不追加整轮开销。L32/L37分别建立磁力菇任务格，保留寒冰套、裂荚套和原示范起点格，不覆盖旧任务名。专项限定1.0倍、开局决策0，现有队列会自动升倍率，调低`starved_beta`不能锁倍率，需主控安排独立固定任务采集或最小的队列限定。收益预期是补上目标任务从空场到首次破防的状态分布，尤其L32/L37此前为零的同卡组开局覆盖。

**学生自身轨迹要有固定份额，混合轨迹补足成功建设过程。** 每个24局组建议12局β=0学生执行、12局β=0.5混合执行，两类均由搜索老师打标签并分开记胜率。优先把L29第9波、L32第23波这类“车已消耗、危险路再入后场”的状态收入β=0轨迹，混合组则保留能持续建成经济和防线的后续段。已有的β混合不应被当作全部解决方案，L23/L24已经以混合组为主，仍只有很少训练行。L19仍需要完整打到29/30波的覆盖，不能将八关统一截到前10波。

**先用已有标签权重做一个轻量对照。** 对上述新专项标签设`label_weight=2.0`，其他配方参数保持不变，不调整全局等待采样。2.0是首轮实验值，尚无最优性证据。按同一份新增语料比较权重1.0与2.0，观察小关卡份额能否转成闭环胜率，同时保留原语料以约束遗忘。需要报告每目标关实际保留行和训练行，不能用264局代替实际行覆盖，也不能声称2倍行权重让目标关自动占到某个百分比。示范起点继续服务中后盘，不抵扣1.0倍开局份额。此轮无需新增逐行权重器或手写战术规则。

**晋升沿用现有门禁，专项用记分板判收益。** 训练候选先跑现有晋升门禁，不修改通过条件，第20轮已有白天回退的直接证据。任务专项在既有32种子记分板上与同一r11逐种子配对，逐关列出救回局数与新增输局数，主指标为闭环胜局，优先看L29/L32/L37。此前16个老师种子仅用于量化老师可赢空间，无需重跑老师全集。此轮8个代表种子已用于诊断，不能作新的未见泛化证据，其余种子用于核查收益能否外推。若现有32种子的配对结果仍不确定，再用既有种子分配机制安排独立评估块，评估种子不进本次训练。

首车波次、后场再穿透和经济存活数只作解释指标。L24与L29样本已经证明“首车更晚”无法单独判定策略更好。若专项胜率改善但现有门禁失败，保留为未晋升候选，由主控决定下一轮配方，不能因弱关提升直接替换生产模型。本任务交付诊断，不执行采集方案或上线。
