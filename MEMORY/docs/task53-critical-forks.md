## 为什么
三条线各自走到了同一个结论：
- **雾区**（task45 追加 E，`MEMORY/docs/task45-fog-terminal-diagnosis.md`）：v4 叶值与终局结果的排序一致率只有 60% / 55%，接近随机。全合法动作接终局能找出局部改善（如土豆雷），但现有搜索因为候选与叶值的问题选不到。
- **屋顶**（task46 第二、三阶段）：叶值分差低于 0.02 锚定门槛，静态候选可能漏掉改善动作。
- **价值网 v5**（task43 第二轮）：40% 的 root 有胜负差异，真实老师分叉接终局能产出有效的排序对。

所以"在关键决策点上，对全部合法动作做完整续走到终局"是一个通用的标签来源。它同时服务两件事：
1. 学生的纠正标签：在老师搜索选不到的地方告诉学生更好的动作；
2. 价值网的决策级排序对：v5 要的就是这个。

这对应计划里"强对策型僵尸"方案的第 2 步（2026-10-23 22:05）。
