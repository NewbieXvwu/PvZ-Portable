## task14：B3 非劣性扩样（新种子 256 局，2026-10-20）

task13 的 B3 只少 1.56pp 却因 256 点区间过宽而无法判不劣。本轮按预登记（08:21:58，base `a66e370`）改用**全新种子 30032–30287**（与 30000–30031 无重叠），每局 8 个根、共 2048 点，抽样规则与task12相同：有合法种植动作，且学生选择种植或距上次假想搜索≥300 tick，再用`Random(20261020+seed)`均匀抽8点。A 与 B3 只差候选生成：A 为静态每卡1+等待+学生原动作+额外2个不同学生动作，B3 为学生全局前3个种植+等待+学生原动作（无每卡下限、无静态打分）。两轻老师共享`D=seed×10000+decision−1`，均用samples3减半、V9验证、margin0.02、min_gap300、horizon2500、mask61。共同重老师对每个公共池动作跑64共同未来、用v3叶值全池评分后做V18锚定验证。公共池保留task12的两静态每卡前2、两原候选及每卡一个额外随机合法格，补齐A/B3全部候选并统一排序；Mac只生成参考池候选，不运行第三条轻老师臂。

样本量按 task13 的整局 SD 0.06920 与 assumed −1.5625pp 估算 244 局达 90% 功效，固定 256 局（2048 点）。中期检查只允许资源闸门：首批 128 局 active >5400 s 才停，不看功效；实际首批 1252.13 s，故按计划跑满 256 局。统计代码 `2143312` 在首次真实汇总前冻结（`stats_freeze.json` 记 `before_any_actual_aggregate: true`），单次终局检验、无多重比较。

**主结果（2048 点，整局为聚类单位）**

| 指标 | A | B3 | B3−A / 节省，95%CI |
|---|---:|---:|---:|
| 与同一重老师一致率差 | — | — | −19/2048 = **−0.93pp**，t 区间 [−1.67, −0.18]pp |
| 整局 bootstrap（10000 次） | — | — | [−1.66, −0.20]pp，与 t 区间一致 |
| 实际续走（条/点） | 34621（16.905） | 26618（12.997） | **省 23.12%** [21.61, 24.65] |
| CPU 秒/点（worker+模拟器） | 0.7380 | 0.5215 | **省 29.34%** [27.57, 31.10] |
| 每局8个抽样搜索根的 CPU 秒 | 5.904 | 4.172 | — |
| 候选数/点（含等待） | 5.961 | 4.001 | — |

预登记门槛为一致率差 95% 下界 > −3pp：**下界 −1.67pp，非劣通过**，bootstrap 亦通过（`robust_NI: true`）。同动作根 1919/2048 = 93.70%；判分根 129 个（6.30%），其中只 A 对 45、只 B3 对 26、两者皆错 58。净失分19点，且95%区间整体低于0，支持对该重老师的一致率有小幅下降；下降仍在预登记3pp容忍界内。同动作时，对任何共同标签H都恒有 `1[B3=H]−1[A=H]=0`，这1919点以差值零计入全部2048点的估计，未将其判为双方正确。

CPU计时逐臂相加Python worker的user+system与活模拟器的user+system，包含静态选格/学生排序、减半、验证及叶值评分；排除共享根动作、轨迹生成/重放、模型/进程启动和重老师审计。A/B3测量先后按(seed+decision)%2交替。表中“每局”仅指8个抽样搜索根，不能作为完整生产采集一局的CPU。

成本构成：续走减少主要来自减半阶段（12.255→8.849 条/点），验证阶段仅 4.649→4.148；模拟器 CPU 0.7024→0.5068 秒/点，Python worker 0.0356→0.0148 秒/点。重老师侧实际续走122816条truth+4248条验证；A/B3两比较臂合计61239条，含重老师的整轮总计188303条，严格重放 278120 帧，256 局全部终局。

扩样审计墙钟（4 worker）：首批128局1252.13 s、次批128局1500.78 s，合计2752.91 s（约46分钟），包含轨迹生成、重放及重老师审计，不代表生产老师采集吞吐。资源原始值以KiB记录，按1024²换算：RSS峰3.24 GiB、自有swap 0、可用最低4.24 GiB，无内存暂停。回归 224 项 Python + 9 项 dsh 全过、无 skip。

**结论**：B3 对该重老师的一致率下降0.93pp（95%区间整体低于0），下降幅度在预设3pp不劣界内；同时少23.1%续走、少29.3%搜索CPU。这是有小幅标签损失的成本折中，不是严格无损替代。
