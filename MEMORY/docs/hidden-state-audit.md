# 全游戏隐藏状态审计

审计日期：2026-10-17。范围以当前任务 day_l7_z15_eval 为第一层，以冒险模式 50 关实体机制为第二层。源码行号指本分支审计时的源码。

## 结论：第 7 关优先补齐的 10 项

最影响胜负的缺口集中在三个地方：网络把完整公开观测压成了粗糙栅格；植物与僵尸的行动阶段被合并；波次实际名单和刷新节拍没有进入普通观测帧。注意：JSON 完整观测已经含有不少计时器与状态，信息丢失主要发生在 `render_episode._frame()` 和 `featurize_numpy()`；Lean JSON 本身也会删去植物状态等字段。公开 JSON 与网络特征不能混为一层。

现行任务在 `playthrough=2`，第 7 关实际为 30 波。第 7 关可出的基础僵尸是普通、路障、撑杆跳；铁桶僵尸从第 8 关开放。波次的具体名单由随机数预先抽取，普通观测不公布名单，特权观测会输出完整 `hidden.zombies_in_wave`。任务倍率在 1.3–1.5；实测任务的 3 个快跑种子里，学生赢 2/3，平均到第 28.67 波。
