# task127：降低学生训练的种子方差（权重平均 EMA / SWA）

主控 2026-10-27 派给 Mac codex-plus2b。分支 `seedvar`，基于 `origin/pvz-env`。在 Mac CPU 上跑（Mac 现在空闲，最多 12 个进程 / 线程合计）。

## 背景

task125：同数据同配方，第 20 轮两个训练种子在 L7 换卡组同 32 种子上 4 vs 28 胜；第 21 轮 A 5 胜。没见过的卡组上的泛化是种子抽签。task126 用挑选面板 + K=4 去“筛”，这是治标；本任务看能不能从训练上把方差本身压下去。

## 要做的

1. 在 `train_rollout_policy.py` 加可选的权重平均（EMA，衰减作配方参数；或末段 SWA），缺省关闭、行为逐位不变。评估 / 导出用平均后的权重。
2. 缩小规模复现方差：从台式机第 22 轮语料取一个子集（例如按标签抽 10–20%，在 Mac 上可训；用 HF `transfer/` 或 scp，用完即删，AGENTS §2），配方同 dw4i2，**4 个种子 × {无平均, EMA}**。
3. 评估：每个模型在 L7 换卡组（`day_l7_eval_d7p_holdout1`）和 L7 原卡组上各 32 局（用记分板式的独立种子段，DESIGN 登记），报告每组 4 个种子的胜局分布（均值、极差、标准差）。预登记判据：EMA 组换卡组胜局的标准差 ≤ 无平均组的一半，且均值不低于无平均组 − 2 局。
4. 若子集上复现不出方差（4 个种子都差不多），如实报告，并说明子集规模与生产差异。

## 预登记（训练与效果测量前，Mac本地2026-10-26）

基于 `origin/pvz-env` 的 `00cfd5df`。新增配方参数 `ema_decay`，0表示关闭，取值须在[0,1)内。实验只比较0与0.999两组，每组训练种子1/2/3/4，从零初始化，成对使用相同数据和批次随机种子。每次优化后更新平均，首次更新复制当时权重，此后按固定衰减累计。验证、各轮检查点和最终model.pt均取平均权重，在线训练参数继续供优化器更新。不按测量结果换衰减或选训练轮次。

语料从台式机第22轮冻结的 `round_000022/recipe.json` 取。用 `random.Random(127).sample(sorted(labels), ceil(0.1*len(labels)))` 一次选出65/641标签（10.14%），对应2,378,514/19,799,497保留行（12.01%）。复制的是该轮已经打好的65个不可变数值分段，合计约1.35GB，保留原标签权重及等待抽样。不传2.08GB原始帧、不重新打包，在Mac直接调用现有 `read_segments` 装载与共享映射，训练器的损失与优化路径保持原样。分段源、行数和原配方摘要随 `subset.json` 记录。通过本任务允许的scp复制，远端仅创建临时传输包，不操作qc或生产训练，复制后删除传输包，八模型训练完成后删除本任务语料副本。

沿用该轮A配方dw4i2的12轮、宽度64、批量2048、验证批量4096，AdamW学习率0.002及余弦调度，v2观测、身份卡包头、meanmax与行池化均不变。仅把设备改为Mac CPU，特征准备并发设1，训练串行，每个训练器3个CPU计算线程，不与评估同时运行。本任务进程与线程合计限制在12以内。初次双训练器配置在第1轮完成前发现框架线程池超过预算，已停止，正式实验改用独立serial目录，未使用中止运行的模型或测量结果。

报告按训练种子1至4依次列出胜局数，另列均值、极差与样本标准差（分母3）。主判据保持任务书要求：换卡组EMA标准差不超过无平均的一半，同时均值不低于无平均均值减2局。若无平均组极差不超过2局，按子集未复现明显方差解释，即便数学判据成立也不据此声称降低了生产方差。原卡组结果完整报告，不增设挑选或采用门槛。仅使用最终12轮模型，不在本次评估上挑轮次。
