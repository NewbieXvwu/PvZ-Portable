## 追加（2026-10-27 用户报告）

- **僵王关 L50 的稳健判定是坏的**：该关 `obs["wave"]` 整局恒为 0（`wave_history` 只有 wave 0，8 个获胜种子的 `final_wave` 也是 0），而 `delivery._robust` 只认检查点 "10"，`_wave_tick(10)` 永远返回 None，所以“3 个稳健”在合法 API 内不可能达成。第一轮由用户授权把 E50 的稳健要求降为 0 绕过。新包里凡是还保留 Boss 关或别的不推进 wave 的任务，稳健检查点要换成不依赖 wave 的定义（例如按 tick，或按 Boss 血量阶段），并加一个小测试。

## 修订 1（2026-10-27 用户建议，主控采纳）：卡组交给打关的模型选

用户：真正在打关的模型对卡组优劣的感受比主控准，应该让它自己选卡；打到一半觉得换个阵型更顺手时，可以换卡重开；同时尽量多打不同卡组、不同流派，扩充数据。上面第 1 节的“F/G/H 各配固定卡组”据此改成：

1. **任务按关卡定义，不绑定卡组**。F 层是屋顶 L42–L45、L47–L49，H 层是白天 L2/L6/L8、夜间 L12/L16/L18、泳池 L22/L26/L28、雾夜 L32/L36/L38，全部原版 1.0 倍。G 层取消，并入 F 层的“多卡组”要求。
2. **API**：`Game(task_id, deck=[...], reason="...")` 由模型给卡组和选卡理由。包里只做硬校验，都是引擎或游戏本身的约束：
   - 长度 6–10；
   - 只能用冒险模式到该关时已解锁的植物；升级植物视为已购买，`owned_upgrade_plants` 自动带上；
   - 地形覆盖：水路要有睡莲，屋顶要有花盆。
   不施加卡组规则 v5 的黑白名单，选废卡的后果由模型自己承担，这本身就是数据。记分板卡组作为“参考卡组”写进任务说明，第一次进关可以先试它，不强制。
3. **换卡重开**：`game.abandon(reason="...")` 结束当前局，存档照常导出，标记为放弃并保存理由，算一次未通关，不扣别的。之后可以对同一种子换卡组重开。开局前玩家本来就能看到出怪预览，所以不算作弊。
4. **达标标准**：鼓励多样，不追同一套卡组刷稳健。每关至少 3 套**彼此明显不同**的卡组（两两至少差 3 张卡，且主力输出或核心思路不同，例如投手流、蘑菇夜战、毁灭菇爆破、忧郁菇加大蒜、地刺阵）各赢至少 2 个种子，全关合计至少 6 胜；其中至少 3 个种子过稳健测试（第 10 波检查点 k=8 赢 5 局，不限卡组）。稳健测试复现时用该局记录的卡组。
5. **存档与报告**：存档里记录卡组、选卡理由和放弃理由。`report.md` 每关列出试过的卡组、各自胜负、模型对每套卡组优缺点的一句话评价。主控会用这些评价修订记分板卡组和卡组规则。
6. **任务量**：F 层 7 关 + H 层 12 关，每关至少 3 套卡组，合计 57 套以上卡组的胜局，足够跑满一次会话。
7. 第 4 步的本地冒烟改为：1 个任务，自选卡组建局、放弃、换卡组重开、存档，各走一遍。
