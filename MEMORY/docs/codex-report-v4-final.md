## §D 当前一句话结论与下一步

**按当前证据强度排序**：① “至少两行火力不足时，输局错失可行动射手机会更多”是显著关联（+15.4 pp，局级 p=0.000060，95% CI [+8.0,+22.5]），但属于观察关联；② 在首次突破点后优先补火力的 I2 对 I0 未通过 Holm 校正（p=0.0938），且实际种下率很低；③ 向日葵优先 I3 反而显著高于 I0（8/15 对 0/15，Holm p=0.0313），所以“补向日葵救不了”被本样本反例否定。**目前不能把“死亡螺旋由火力优先响应错误导致”定为根因；干预只证明这批失败簇中重播策略会被干预改变，未证明火力优于补经济。**
