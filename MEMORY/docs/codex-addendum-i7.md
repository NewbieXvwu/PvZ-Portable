| 指标 | 赢局 | 非赢局 | p |

**★ 非平凡细节**：赢局在"有路裸奔"时比平时**更少**种在身后（0.485 < 0.537）；

**★ 这可能就是上一轮 I2g/I3g 干预失败的真正原因**：它们只按"火力最薄的行"选**行**，
**没约束"种在僵尸前面"**。落点若仍在僵尸身后/同列，那株射手照样打不出伤害。

**★ 与教师诊断独立收敛**：上一轮 10 个教师会话的合并结论是

## 3. ★ 核心实验：I7 定向补位

**选局**：沿用 v4/v5 冻结的 **15 个失败 seed**（与 I0/I1/I2/I3/I4/I2g/I3g 同一批，保持可比）。
这批 seed 与 I0 的原始结果在 `/tmp/n4_A1_results/A1_seed_<seed>_I0.json`（15/15 与源档案全帧一致）。

**触发点**：**首次出现"承压裸路"的那一帧** —— 某路有在场上僵尸、且该路
`_reachable_dps(...)[1] == 0`（0 株能打到最前僵尸）。多路同时裸时选**最前僵尸列最小**（最深）的那一路。

**干预内容**（从触发点起连续 **10 个决策**，与 I2/I3/I4 同窗口长度）：

| arm | 干预 |
|---|---|
| **I7 ★** | 在那条**裸路**上强制种射手，落点列 **严格 < 最前僵尸列**（优先 `front_col - 1`，不可用则往前退），要求该列空格且卡片合法 |
| **I7b（落点对照）** | **同样那条裸路**，但落点列 **>= 最前僵尸列**（种在僵尸身后/同列）—— "路对但位置错"的对照 |
| **I7c（可选）** | 那条裸路种**向日葵**（不是射手）—— 检验"是不是射手本身重要" |

**判据（关键，四种情形都要写清）**：
- **I7 显著优于 I7b** → **"落点"是真机制**（不是"种了就有效"）
- **I7 显著优于 I0** → 定向补位能救局
- **I7b ≈ I0** → **"种在身后等于没种"**被证实
- **I7 ≈ I7b** → **落点不是关键，本分析被否** → 那就明确写"被否"，并说明下一步该查什么

**统计**：与 I0/I4 同族做 Holm 校正（**逐步下降法**，且**报告正文的数字必须与同一份 JSON 一致**
—— 上一轮 v4 正文与 JSON 对不上过一次）；**同时报 ahead/behind 的实际送达率**。
