## 执行结论

### 1. 历史整局降采样

`label_weight`、`source_weight` 和 `level_balance` 都只调整行权重，仍会加载全部行。因此增加默认空的 `label_keep`，配方示例为 `"label_keep": {"dagger_old_": 0.25}`，实际使用时把示例前缀换成历史标签前缀。键是从标签开头匹配的正则，精确匹配用 `$`，重叠规则取最低保留率，未匹配标签保留全部。比例支持 0–1，同一“种子目录/标签目录”的 SHA256 决定整局去留，与轮次、语料增长和绝对路径无关，不补偿行权重。存档重命名会改变抽样身份。

关闭时不传字段，或设 `{}` / 保留率 1，打包标识与原来相同，训练行逐位保持。单独打包可传 `--label-keep '{"dagger_old_": 0.25}'`，课程打包与训练从同一配方传递参数。完全丢弃的标签不产生空段，整份语料被丢空时直接报错。

重打包只重建实际降采样标签的不可变段，其他段直接复用。保留存档仍可复用已有特征缓存，哈希筛选不解压帧。首次启用或调整比例要重新组装受影响标签的保留行，另写一个小索引，旧段不删除。代价随保留档案和缓存冷热变化，本任务仅运行秒级合成小样本，未启动全量重打包。

相关小测试已通过：配方规则校验、默认关闭逐位等价、整局确定性、跨目录/新增标签一致，以及未受影响段复用。
