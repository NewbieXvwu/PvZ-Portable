> 主控 2026-10-24 设。执行：Mac `cb-demo`，工作树 `.../worktrees/demo`，分支 `demo`。

## 结论（一句话）

**L31 是卡组问题，L32–L34 不是。** 同一个老师、同一关、只换一张卡（路灯花 25 → 寒冰射手 5），
L31 冷启动从 **1/32 变成 25/32**（78.1%，95% CI 61–89%，配对 McNemar p < 1e-6）。
其余 7 个用户卡组族在 32 个种子上都是 0–9.4%，与对照卡组（每关 0/32）没有显著差异 ——
L32 的瓶颈是前期经济，L33/L34 的瓶颈是防空（气球僵尸）。

**建议**：把 `demo_fog_31_snow`（1.0 倍）接进 qc 课程，作为雾夜第一个冷启动起点；
L32–L34 不接，改用 task64 的示范起点做倒推课程。接不接由主控定。

每局平均种植数（`planted_types`）：

| 族 | 主要种植 | 经济 | 输出 |
|---|---|---|---|
| `fog_user_l31_fume` | 小喷菇 9.5、**路灯花 4.3**、窝瓜 3.1、水草 2.9 | **阳光菇 2.7** | 大喷菇 0 |
| `fog_user_l31_snow` | 小喷菇 24.9、窝瓜 12.5、水草 10.8 | **阳光菇 21.6**、睡莲 16.0 | 大喷菇 8.3 |
| `fog_ctrl_l31` | 土豆雷 2.2 | 阳光菇 8.5、睡莲 6.7 | 豌豆射手 0.0、寒冰射手 0 |

同一关、同一个老师：**卡组里有路灯花时，老师每局花 4.3 个格子去种它，阳光菇只剩 2.7 株**；
换成寒冰射手后，阳光菇 21.6 株、小喷菇 24.9 株、大喷菇 8.3 株，整局搜索 199 次、推翻学生 55.7 次
（fume 只有 109 / 9.3）。也就是说：**路灯花不是"占了一个卡位"，它把老师的经济节奏带偏了** ——
静态网给它的分高，老师反复种它，前 10 波既没有阳光也没有输出。

对照卡组的问题更直接：它没有便宜的输出（豌豆 50 阳光起、香蒲要睡莲），老师每局只种出
8.5 株阳光菇 + 6.7 株睡莲 + 2.2 个土豆雷，第 8 波就被打穿。

## 6. 判断与接入建议

按任务书的标准（用户卡组 ≥25% 且配对显著 → 建议接入；仍接近 0 → 瓶颈不在卡组）：

1. **L31：是卡组问题，且只差一张卡。** `demo_fog_31_snow`（1.0 倍）冷启动 25/32 = 78.1%
   （CI 61–89%），配对 p < 1e-6，**建议直接接进 qc 课程，起始倍率 1.0**。
   这也是雾夜区第一个通过 50% 门槛的冷启动族（task45 时是 0/384）。
2. **L31 fume 不要接**（3.1%）。它与 snow 只差路灯花/寒冰射手这一张卡，同一批种子下 1/32 vs 25/32 ——
   这张卡在 L31 就是决定性的，不需要再讨论倍率或策略。
3. **L32–L34：不是卡组问题（至少不是这一组卡组）。** 四个用户卡组里三个 0/32，最好的 9.4%，
   与对照的差异都不显著。按 task64 的结论，这三关应该改用**示范起点做倒推课程**：
   从人类局的中途（老师能接住的最早位置）接手，而不是指望换个卡组就能冷启动。
4. **若以后要在 L33/L34 做冷启动，先解决防空**：这两关的输局里气球僵尸是主要破防者之一
   （L33 cactus_snow 30 局输局里 29 次气球到家），而卡组里的仙人掌几乎没被种下去。
   这是"卡组里有牌但用不出来"的问题，不是"卡组里没牌"。
5. 接不接 qc、先接哪几族，由主控定。

## 问题

1. **对照卡组不是 task45 的 `fog_l3x_*` 原表。** 那份清单只存在于 Linux `fog` 工作树的
   `artifacts/task45/`，本机没有（全盘搜过）。本次用 `pvz_tasks.deck_for_level(31..34)`
   的 qc 雾族卡组 `[0,9,2,3,4,5,16,43]` 作对照 —— task45 的 f8 就是从它派生的。
   对照四关 0/128、平均第 8 波崩，方向与 task45 的 0/384 一致；但严格说这不是同一份卡组，
   数值不可逐位比较。
2. **32 局/族的区间很宽。** 3.1% 的 Wilson 上界是 15.7%，所以"接近 0"和"5%"分不开；
   反过来 L31 snow 的区间下界 61% 仍远高于 50%，这一条结论是稳的。
3. **只测了 1.0 倍。** L31 snow 在 2.0 倍（`demo_fog_31_snow_m200`）下没测；
   如果要提高难度或做课程阶梯，需要另开面板。
4. **种子没有与 task45 的全库审计交叉。** task45 扫过 329281 份清单、572554 个种子，
   那份索引不在本机。本次只保证与示范种子 20261031–34 不重叠；20261101–20261132 是否
   曾在别处评估过未核对。
5. **`fog_user_l33_blover` 与 `demo_fog_33_blover` 卡组相同**，只是种子集不同（评估族 vs 示范族）。
   同理 `fog_user_l31_*` 等。这是为了不污染旧族的种子（AGENTS §8、task67 规则"旧族不变"），
   代价是清单里多了 12 个族。
