## 3. 晋升评测

1. **每轮只训 2 个候选**：A、B 配方各一个种子。训练时间减半，轮次不再被跳过。
2. **取消单独的挑选面板**：两个候选都与现任在同一批种子上配对，A、B、现任三方同种子。
3. **序贯检验**：门禁改成序贯检验，结果明显时提前停；上限仍为 1728 对。
4. **晋升规则**：
   - 两个都通过：晋升总体点估计更高的那个；
   - 只通过一个：晋升那一个；
   - 都不通过：不晋升。
5. **防漂移**：在“总体下界 > −3pp”的非劣条件之外，再要求点估计 ≥ 0。连续几次“略差但不显著”的晋升会把水平慢慢拉低。
6. **面板自校准（阶梯法）**：
   - 每次门禁后，双方胜率都 ≥ 90% 的任务，下一次提高一档倍率；
   - 双方都 ≤ 10% 的任务，降一档，或改用示范起点；
   - 目标是让现任胜率落在 30–80%；每个地形的任务数不变。
7. **连续终点**：低胜率任务一律用存活波数做配对终点，把 v6 屋顶的做法推广到所有地形。
8. **现任必须是当前现任**：门禁对比的是开评时的现任，而不是入队时的快照。激活必须写入状态后，才算组边界已提交。
9. **留出监控保留**：不否决；但出现像 holdout1 67 : 5 这样的大幅退步时，在日志里报警，由主控决定。

## 4. 研究对照（配方、结构、采样）

- **生产内配方对照**：每轮记录 A−B 在同一门禁种子上的配对差，跨轮累计。预登记：累计 ≥ 6 轮，且跨轮符号检验或配对 t 检验 p < 0.05，才换配方。
- **离线实验**（E4 结构、task176 KL 采样等）：
  - 每臂 ≥ 3 个训练种子；
  - 按种子做统计，不把不同种子的对局混在一起；
  - 报告 IQM 与分层 bootstrap 区间（rliable）；
  - 真打评测用同一个自校准面板，外加陌生卡组面板。

## 5. 北极星基准（不参与晋升，只看走势）

每次晋升后，Mac 自动拉取新学生跑一遍，结果画成随时间变化的曲线：
- **通关**：冒险 1–50 关，原难度、标准卡组，纯学生每关 16 个种子；有余力再测老师（搜索）。
- **泛化**：54 套陌生卡组，每套 2 个种子。
- **难度**：几个代表关的倍率阶梯，记录胜率 50% 时的倍率。

## 6. 训练：热启动候选

- **做法**：B 槽位的下一个实验是热启动——从现任初始化，新数据加权、旧数据均匀回放，训 2 个 epoch。
- **采纳条件**：若跨轮累计不差于 A（从头训 12 epoch），就改为默认。
- **收益**：训练时间约降 5 倍，同时直接解决“每轮只新增 0.4–2% 的行，98% 是旧数据”的分母陈旧问题。
- **防可塑性丧失**：每 N 轮仍从头训一次（Dohare 2024）。
