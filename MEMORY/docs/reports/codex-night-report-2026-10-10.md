## 2. 哪些猜想被**证实**了

| 猜想 | 结论 | 关键数字 |
|---|---|---|
| **价值函数是烂的，因为 critic 根本没训过** | **证实** | BC 检查点里虽有 critic 权重，但与初始值**完全相等**，且 BC 训练脚本只有动作损失、没有价值目标 → 它就是个没学过的随机初始化值。这解释了"价值解释方差常为负（最差 −10.7）" |
| **胜负率这个尺子太钝** | **证实** | 256 局时胜负率 95% 置信区间半宽 **4.07 个点**，要压到 ±2 点得跑 **1,062 局**；换成"平均推进波数比例"只要 **212 局**，**灵敏 2.3 倍** |
| **它输的时候输在"火力不够"** | **证实** | v3 1M 按胜负分组：胜局峰值火力 **22.28** vs 败局 **16.42**；胜局杀敌 157 vs 败局 40；败局明显"少种、少花钱、多等"（等待动作 +325 次） |
| **训练时相邻两批用的种子高度重叠** | **证实** | 每批 16 局平均只覆盖 **13.40** 个不同种子；相邻两批的种子集合交集高达 **0.807** → 批次之间高度相关，等于没充分采样 |
