# task174：学生 v3 生产通路

分支 `v3prod`，基于 `origin/deploy19`（8eb35d86）。先登记任务，再实现，完成后提交推送并停下等主控。本任务只准备生产通路，不部署，不改变现行 CNN 配方或启动配置。

## 目标与默认行为

复用 task163 的 StudentV3 与 `origin/tokenstore` 的32行稀疏压缩块、块级打乱和有界多进程预取，接入现有生产打包与训练入口。由配方的网络选择字段启用 v3，未选择时继续使用原 CNN 路径。富输入直接读取已有 obs v3 附件，保持输入 `frames[i−1]` 对标签 `frames[i]` 的行对齐，不生成全库密集 token，不重放或回填存档。v3 训练需要具有富附件的数据，不能用旧紧凑帧伪造缺失特征。

训练产物通过 task161 的导出器生成 `PVZGN001`。采集时可显式选用独立 v3 根策略，搜索续走继续使用 CNN，沿用 task161 的独立根/续走能力。挑选和门禁入口可以加载、评测 v3 检查点。新增网络及策略选择全部默认关闭，启用由配方与启动参数完成，不增加独立训练器或新的部署流程。

## 接入边界

生产打包和候选训练沿用现有行采样、权重、档案划分及训练入口。稀疏 token 随原不可变 label segment 保存，合并只复制压缩块及行地址，minibatch 才解码。95k行/秒为 task163 在台式机小样本热缓存下的稳态读取结果，本任务复用实现，不把它表述为 Mac 端到端训练速度。

原生运行复用 task161 的通用图、富输入适配和独立根策略接口，保留已上线的采集附件、门禁v6及资源路径清理，不合回旧分支中已删除的摘要、清单或重复验证。生产模式仍由主控选择研究结果后开启。

## 一次性 Mac 演练

在独立临时目录，用一小段真实 obs v3 数据跑通现有训练入口 → PVZGN001 导出 → 原生 v3 根节点配 CNN 续走 → 现有挑选入口。需要时独立构建 Mac 引擎，生产引擎与进程不动。按 AGENTS §6.5 第8条控制资源，只执行一次集成链路，不保留演练脚本或常驻检查。结束后删除临时目录。

不新增校验、manifest 或 JSON 中间文件。只使用现有生产接口的标准产物，模型、数据和日志不入 git。结论和启用方法追加本文。
