## 为什么

第 12–22 轮共 11 次否决，**9 次含 heldout 否决**，heldout 每一轮都退步（−3 到 −42pp），总体不过关也主要被它拉下（占门禁 20% 对局）。去掉 heldout，第 14、22 轮其余各区基本都在进步。崩塌集中在一个任务 `day_l7_eval_d7p_holdout1`（`[0,1,2,27,5,32,3]`：白天带三叶草这种废卡、靠卷心菜输出）；L9 heldout 新学生反而更好。新学生把雾夜学来的“三叶草有用”迁移到白天，同时冷落卷心菜。冒险模式里我们每关用自定卡组，永远不会遇到这种组合；目标顺序是“先通关、后泛化”，现在的门禁把泛化排到了通关前面。
