# v5（2026-10-27，用户反对意见 + 与 Gemini 第四轮）

**原则改为：只禁“零作用”（物理上种不了，或种下永远不会触发）。“需要多一个动作 / 多花阳光 / 玩家觉得弱”不是禁用理由——那是在卡组层面替模型做策略判断。**
用户原话要点：忧郁菇 DPS 极高、打上下两路，前面一个大蒜就很强；多倍出怪下大喷菇的无衰减穿透很高贵；寒冰菇全屏冻很强。环境核实：咖啡豆就是“种在睡着的蘑菇上”，引擎 `CanPlantAt` 只在睡着的蘑菇格放行，动作空间支持。

相对 v4 的变更：
| 项 | v4 | v5 |
|---|---|---|
| 白天蘑菇（8,9,10,12,13,14,15,31,42；白天泳池含 24） | 全禁 | **解禁**；白天带任何蘑菇 → 必带 35 咖啡豆；无蘑菇 → 禁 35；白天 42 → 10 + 35；夜间 42 → 10 |
| 弱卡池与“每套最多 1 张” | 有 | **取消**（大蒜、仙人掌、裂荚、杨桃、大嘴花按普通卡抽；大嘴花配墙的约束也取消） |
| 屋顶 26 仙人掌 | 禁 | **解禁**（主控纠正 Gemini：屋顶第 5 列起是平地，直线射手可用；仙人掌与豌豆同理，不是零作用） |

| 雾夜 27 三叶草 | 保留 | 保留（我们的雾夜观测有遮蔽，吹雾有作用） |
