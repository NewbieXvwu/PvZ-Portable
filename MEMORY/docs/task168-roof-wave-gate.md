## 预登记判定与实现口径

来源为 `origin/gateslim:MEMORY/docs/task166-gate-slim.md` §0 第4条与 §6.2 E11b。屋顶 L41、L46 从二值分区否决族移出，使用同种子的 `candidate.final_wave - incumbent.final_wave`，按 E11b 的屋顶90对口径合并执行一次单侧 Wilcoxon 符号秩检验，备择为候选存活波数下降，α=0.01。屋顶分区p<0.01即否决，两项的均值差和单项检验另列作诊断，不驱动独立否决。

统计单位的澄清：最初实现按两个任务各45对检验，回放发现r29 L41的p=0.0362588，L46的p≈4.79×10⁻⁸。L41单项无法满足α=0.01，因此不能声称两项各自显著。最终使用原E11b已经写明的屋顶合计90对，合并p≈1.08×10⁻⁶；未更换检验、α或波数口径。这个口径修正及单项限制在结论中保留。

零差对从秩计算中丢弃，绝对差并列时取平均秩，全部零差返回p=1。用加倍的整数秩动态规划精确计算符号翻转分布，包含观测统计量所在尾部，不用随机重采样。两个45对任务的计算量很小，预计毫秒级，不增加对局或生产预检。零差及并列秩的约定见 [Wilcoxon 参数说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wilcoxon.html)。实现保留现有标准库依赖。

其余四区仍按单侧精确 McNemar 和 Holm 家族α=0.05判定，家族由五区变四区。总体冒险任务胜率与 −3pp Newcombe 区间条件保留，屋顶二值结果继续计入总体并单独报告，heldout继续只监控。卡组、对子数和种子分配均不改。

新契约使用门禁版本6，冻结面板标记为 `v6-task168`，来源仍为 `configs/gate_v5_panel.json`。旧版本1–5的统计路径保留，版本6的配对记录补充双方存活波数，旧结果不得作为新版证书复用。

历史范围为r26–r36的全部现存门禁：r26、r27、r28、r29、r36，r30–r35无decision；r27两份结果按候选/现任摘要及配对结果核对后去重。验收条件：r29的L41 −2.09波与L46 −4.64波都列入屋顶退步证据，并触发屋顶分区否决，r27的L41 +5.53波与L46 +3.11波不得被误判为退步。若要求两项分别达到p<0.01，L41不满足该要求。
