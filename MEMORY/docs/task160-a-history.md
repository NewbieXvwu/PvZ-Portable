## 3. 最关键的 10 条教训

每条都写"结论 + 证据数字 + 出处"，方便以后直接引用而不是重新论证。

### 1. 容量不是瓶颈；先怀疑数据与输入，再怀疑参数

两次独立的加宽实验都指向同一结论：

- 10-18 d27Cw128：六档前沿 **1.887**，同数据同种子宽 64 是 **1.947**；据此跳过 TRM / DRC 式加深（`MEMORY/docs/student-bottleneck-plan.md:287`）。
- 10-22 task23 同语料宽 128 完整面板：白天 94.6%（64 宽 92.5 / 92.9），但换卡组留出 **53.8%**（64 宽 60.0）、夜间 **42.6%**（51.4），C++ 单步 **3.11×**（`MEMORY/docs/student-bottleneck-plan.md:483`）。

也就是说：加宽只在"训练分布内、早关"有收益，代价是泛化与推演速度。**"打不过"时先查数据覆盖与输入字段，加宽是最后手段。**

### 2. 加宽会伤泛化，新结构必须在"陌生卡组"上不差才算通过

task158 的补充把这条写成了设计约束："参数更多、每个专家分到的数据更少，都可能伤泛化"（`MEMORY/docs/task158-terrain-interference-moe.md:52`）。task153 的实体臂是同一个现象的另一面：未见卡组上等待行误判 11%（CNN64 是 4%），整体动作准确率因此掉 6 个点（`MEMORY/docs/task153-entity-attention-student.md:55`）。

**判据要固定成：任何新结构在"陌生卡组"和"各地形"两个维度都不差于联合 64，才算通过；只看总准确率会放过这种退化。**

### 3. 输入里的连续数值不能外推

`--context` 把出怪倍率喂给学生后，同一个 d35ctxs1、同 256 局 2.0 倍评估局，只改它"以为的"倍率：说 2.0 → **57/256**，说 1.7 → **126/256**，说 1.5 → **65/256**（`MEMORY/docs/student-bottleneck-plan.md:347`）。

结论不是"容量不够"，是"输入落在训练范围（≤1.7）之外，网络对没见过的数值没有约束"。**要么训练数据覆盖目标范围，要么不给这个输入；扩宽 / MoE 都救不了（按倍率路由同样没有 2.0 的专家）。**

### 4. 锚定 DAgger 下 97% 的标签就是学生自己的动作；"只留纠正行"是错的补救

老师覆盖率从 5% 降到 3%，新轮次 97% 的标签 = 采集学生自己的动作（`MEMORY/docs/student-bottleneck-plan.md:388`）。task15 直接测了这个假设的补救方案：只保留纠正 / 高 spread 行 → **−41.7pp**，普通自标签必须保留（`MEMORY/docs/student-bottleneck-plan.md:406`）。

**含义**：DAgger 的价值在"学生自己走到的局面上仍有少量纠正"，不在于"把纠正挑出来放大"。删掉普通行等于把分布打回老师分布。

### 5. 数据变多时先查步数预算，再查配比

D35 比 D30 数据多 23%，胜率低 4.35pp；把步数固定回 D30 的水平（`--max-steps 42456`）恢复 **+4.35pp**（两种子 +5.26 / +3.43，95% CI [2.97, 5.75]）。同一批实验里：恢复旧倍率配比 +3.28pp、倍率全均衡 −13.6pp、只留纠正行 −41.7pp（`MEMORY/docs/student-bottleneck-plan.md:406`）。

而且三个杠杆会互相顶替：在 row_pool + ×1.5 的配方上再叠步数上限，反而 783 vs 815（`MEMORY/docs/student-bottleneck-plan.md:409`）。**"数据加了多少"必须和"步数预算怎么定"一起报，否则配比结论不可信。**

### 6. 搜索标签约六成是噪声；复核要花在"值很多"的修正上

4 局 904 个搜索点：154 次推翻里 H（12 个未来、不淘汰）只认同 63 次，未认同 59.1%；认同 / 未认同的平均价值收益 **+0.144 / −0.017**。K = 9 复核后推翻 154 → 99、认同比例 41% → 58%，代价是每局搜索 +29%（`MEMORY/docs/student-bottleneck-plan.md:84`、`:87`、`:91`）。旧档案重标注撤销约 40%（12b 9,213 / 23,054，13b 8,561 / 21,398）。

**含义**：门槛 0.02 保留，但"小幅推翻"基本不该学；加复核样本是划算的（+29% 搜索换掉 55 次噪声推翻）。

### 7. 整局胜负标签不能给候选排序；要用分叉 / 决策级标签 + 成对一致率

value_self1 在同一局面候选间的成对一致率 **0.55**（v2 0.71），带锚搜索损失 0.108，比学生自己走（0.081）还差——原因是整局结果主要反映难度和种子，不反映这一步的好坏（`DESIGN.md:537`）。改用分叉数据后一致率 0.70–0.82。

但"决策级"也不自动成立：泳池 v5 第一轮把粒度换成决策级，94.5% 的决策所有候选都输，标签仍是常数，验收 (a)(b) 双失败（`MEMORY/docs/task43-value-v5-pool.md:253`）。**标签的分辨率取决于续走策略会不会赢，不是取决于标签粒度。**

### 8. 门禁的假拒比假通过贵得多：64 对 + 赢家诅咒 = 8–10% 通过率

64 对时 −3pp 非劣界对"同等强度"候选的通过率只有 **8–10%**；现役 r5 是在同一批种子上以 48/64 选出来的，后续候选都在跟这个"运气好"的对手比。新种子复测：r11 实际比 r5 强 **+6.6pp [+1.6, +11.7]**，而冻结种子上是 −4.7pp（`MEMORY/docs/promotion-gate-power.md:9`）。真 −5pp 候选的通过率 ≤1%，拦截力没问题。

**含义**：门禁的门槛不能只调 α，还要换种子、加对数（v2 起 1536 对、现役同轮重跑）。

### 9. 门禁的"防泛化退步"会把通关排在后面

第 12–22 轮 11 次否决里 **9 次含 heldout**，heldout 每轮都退 −3…−42pp，崩塌集中在一个白天带三叶草的卡组上；冒险模式里我们每关用自定卡组，永远不会遇到这种组合（`MEMORY/docs/task128-gate-v5.md:7`、`MEMORY/docs/student-bottleneck-plan.md:1008`）。改成 v5（只看记分板冒险关 / 卡组，heldout 只监测）后 r27、r29、r36 才陆续晋升。

**含义**：指标的"目标顺序"必须显式写出来（先通关、后泛化），否则门禁会替你做另一个决定。

### 10. 指标与抽样口径会反向塑造研究：前沿外推、单种子、挑选即抽签

- **前沿外推奖励"曲线平"的模型**：只用第 12–16 轮训练时前沿 1.609（历史最高），但三档胜局都低于 v20；结论是"以后同时看三档胜局是否全面占优"（`MEMORY/docs/student-bottleneck-plan.md:129`）。v20 的 50% 点实测约 1.66，旧两点外推给 1.575（低估）。
- **单种子比较不可信**：同数据同配方，第 20 轮两个训练种子在 L7 换卡组同 32 种子上 **4 vs 28 胜**（`MEMORY/docs/task127-seed-variance.md:7`）。
- **老师也不随学生自动变强**：老师 v16（v17 续走）128 局 108 胜，比 v14 续走的 110、原始老师 118 都没涨（`MEMORY/docs/student-bottleneck-plan.md:80`）。

**含义**：任何"某改动有效"的结论至少要两种子 × 多档；只报一个综合分（前沿、总分、单种子）等于让指标替你选模型。

## 5. 历史回答不了的问题

这些是这份综述**不能**给 task160 决策提供的答案。写清楚是为了让 B（文献）、C（评测工具）、D（生产画像）和实验设计去补，而不是在这里猜。

1. **卡组泛化差，是输入不足、容量不足，还是数据不足？**
   三种结构（CNN64 / 等参 CNN81 / 实体注意力）在旧紧凑输入 + 白天小数据上都卡在约 91%（`MEMORY/docs/student-bottleneck-plan.md:1095`），这只能说明"在这个输入和这个数据量下结构不是瓶颈"。**富输入 + 生产规模数据的四臂对照从没做过**（task157 才刚开始）。
2. **注意力 / 实体结构在空间关系关卡上是否必要？**
   L5 保龄球（滚动坚果的斜率与方向）、L45 蹦极（落点红靶）、屋顶投掷，从来没有和 CNN 比过（`MEMORY/notes/student-architecture.md:9`）。task153 只测了白天 L7–L10。
3. **MoE 到底有没有用？**
   干扰从未测过（第 4 节第 1 条）。"加宽伤泛化"到底是**参数多**还是**每个专家分到的数据少**，历史数据分不开——task23 的宽 128 是前者，task158 要测的专家臂是后者。
4. **记忆值多少？**
   唯一一次测量（K=4 帧堆叠）落在全败地板上（两臂 0/256，`MEMORY/docs/student-bottleneck-plan.md:531`），什么也没证明。雾关现在仍靠示范起点格，不是靠记忆。
5. **价值网冻结的实际代价有多大？**
   task154 在做校准与归因，尚未出结论。已知的是 v5 没见过屋顶 / 雾 / 随机卡组 / GPT 起点卡组（`MEMORY/docs/task154-value-net-staleness.md`），但"换掉能多赢多少局"没有数字。
6. **数据配比里哪个杠杆最值？**
   L7 历史行降采样、随机卡组格配额、示范行加权、LLM 行、B 配方、价值网进循环——**六条路线一条单变量都没跑过**。r36 的 60.3% 历史 DAgger / 47% L7 是已知的分布事实，不是已知的因果。
7. **老师的上限在哪？**
   老师 = 学生候选 + 学生续走 + 价值网叶子；学生不变强，老师也不变强（`MEMORY/docs/student-bottleneck-plan.md:80`）。"根节点换大模型、续走仍用小 CNN"的角色拆分从没试过，所以**不知道现在的天花板是学生、是价值网、还是候选宽度**。
8. **每轮 768 局 / 约 3 小时的采集量够不够？**
   没有"数据量 → 胜率"的曲线。行数从 1.86M 涨到 22.6M，同期胜率也在涨，但中间混着老师变强、倍率变高、配方变化，无法分离边际收益。
9. **训练种子方差（4 vs 28 胜）的根源是什么？**
   只测了 EMA 一个假设（否决）。数据顺序、初始化、留出切分、挑选偏差都没测。
10. **门禁 v5 只看通关之后，泛化会不会长期停滞？**
    现在把泛化排在通关之后是有意的取舍（`MEMORY/docs/task128-gate-v5.md` 末节）。但没有"通关后"的数据，无法判断这个取舍会不会在 50 关打完后立刻变成新瓶颈。
11. **旧档案能支撑富输入回填吗？**
    obs v2 证明"已有字段"可以逐位重放回填（256 局零失配）。但 task157 需要的像素 y、滚动坚果位置、蹦极落点，旧档根本没有（`MEMORY/notes/student-architecture.md:64`），只能从现在起随帧写入。**这意味着富输入的第一批数据要等采集跑起来才有，不能靠历史档案。**

## 6. 一页速查

- **架构线**：`GameplayModelV1`（token + 注意力 + GRU，3.68M，3864 µs）→ 10-10 小 CNN（50 万，追平）→ 10-16 packet_balance/meanmax → 10-17 观测 v2（101 通道 + 122 标量）→ 10-18 格子级软标签（+0.089，最大单项）→ 10-19 按行汇总进配方 → 10-21 identity 头 → 10-22 宽 128 否决（泛化掉、慢 3.11×）→ 10-29 实体注意力暂停（91.0% vs 91.3%）→ 10-29 v3 富 token + 通用 C++ 前向。
- **数据线**：DAgger 锚定标签（97% 自标签）→ 标签噪声约 60%（K=9 复核）→ spread 加权（行）→ 格子级软标签 → 步数预算 H4 → 门禁 v1→v5（64 对 → 1536 对 → 10 任务 × 192 → Holm → 只看记分板）→ 课程加宽（扰动卡组 / 倍率 / 雾 / 屋顶 / 示范起点 / 随机卡组格 / GPT 起点）→ 10-29 才发现 60% 是历史 DAgger、L7 占 47%。
- **一句话**：这个月真正被数字反复确认的只有三件事——**标签质量 > 数据量 > 容量**；**泛化必须单独度量，否则会被加宽和门禁一起掩盖**；**任何"更强"都要在陌生卡组上不掉才算数**。
