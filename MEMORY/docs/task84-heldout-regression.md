## 要回答
r11 → r13 / r14 之间训练数据和配方变了什么？哪一项和“换卡组就变差”有关？

## 要做的
1. **对比配方与数据构成**：r11 / r12 / r13 / r14 的 `recipe.json`、`source_rows.json`、`metrics.json`（都在 `~/pvz-logs/curriculum_state.pipeline/round_*/`）。逐族列出行数和占比，重点看：
   - d7p / d7q 这类扰动卡组族的占比是否下降；
   - 新加入的雾夜、屋顶、示范起点格、高倍率格的占比；
   - 训练步数、学习率、验证损失是否有变化。
2. **定位**：在 heldout 的 192 个种子上，找出 r11 赢而 r13 输的对局，看输在哪一波、被什么破防、学生选了什么卡。和 r11 对比，找出是否一贯少用或多用某类植物（只做统计，不写打法规则）。
3. **消融（预登记后再跑）**：用 r13 的配方训两个变体，每个约 45 分钟（训练用 `train_rollout_policy.py`，参数与管线一致；内存允许时再开）：
   - A = 去掉 r12 之后新加的族的数据；
   - B = 保留新族，但把 d7p / d7q 的采样权重恢复到 r11 的占比。
   两个变体都在同一批 heldout 种子上（192 局）与 r11 配对比较。
4. **方案**：根据结果给出配方或课程层面的修正建议（采样配比下限、扰动卡组族保底份额等），写清预期效果与检验方法，由主控来定。**不改生产**。
5. 结论写 `MEMORY/docs/heldout-regression.md`，`git push origin gatepower`。
