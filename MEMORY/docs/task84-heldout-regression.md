## 主控追加（2026-10-26 04:35，变体 C / D）
消融 A 的结果是：r11 的配方和种子不变，重训一次，heldout 只有 124/192，r11 是 166。这说明 r11 在 heldout 上是一次“幸运”的训练结果，而每轮都从头训，只会不断回到均值。第 15 轮也已经因为 heldout 被拒，课程会一直卡在 r11。B 跑完之后请再加两个变体，评估口径与 A、B 相同：heldout 192 对，加上对照 `day_l7_eval_d7`。
- **C：从现役续训**。用 r13 的配方，`init` 设为 r11 的权重，epochs 降为 3，学习率降为 1/4，其余不变。预期：heldout 与 r11 持平，其他区保留 r13 的新数据收益。
- **D：训练随机性的量级**。用 r11 的配方，只换 `seed`（2、3），训两次。每个 heldout 都与 r11 配对。这样可以给出“从头训练时 heldout 的标准差”，用来判断门禁的 heldout 区是否需要随机性口径。
