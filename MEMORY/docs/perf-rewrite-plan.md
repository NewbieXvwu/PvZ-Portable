# 专家迭代流水线重构（2026-10-16）

## 测量边界

本轮固定 r8（128 通道学生）、Mac branch1 挑格子与 v2 评叶子。
老师沿用 29 / 2500 / 3。
所有产物写入本工作区的 `artifacts/perf/`。
正式实验启动后最多使用四个模拟器进程。

首次实际 DAgger 的单局耗时为 35.10 秒。
其中续走模拟为 25.13 秒，学生预测为 4.31 秒。
Python JSON 解码为 0.35 秒，价值网络批量打分为 1.19 秒。
纯老师同种子为 31.02 秒。
新采样里动画更新占 C++ 主线程的 20.09%，其中附着物路径占 13.30%。
两个动画数字存在包含关系。
128 局学生评估四进程约 15 秒。
128 份历史档案共 143.77 MB，读取原文 / 首建缓存 / 命中缓存为 3.67 / 9.34 / 0.62 秒。
这些小批数据用于定位成本，不能直接冒充全量迭代计时。

## 实施顺序

1. 优先压缩占主要时间的模拟更新。只对可直接证明等价的路径做精确改动。涉及跳过动画生命周期的方案按近似独立验收，保留旧开关。
2. 将特征生成和归档读取从训练器分离。缓存签名只涵盖实际编码与标签提取逻辑，不涵盖优化器和命令行。采用自带特征的压缩归档，同时保留完整棋谱，旧 JSONL 继续支持，混合目录按原有顺序抽样。
3. 用分叉采集的 horizon / 终局计时决定后续工作。当前第二次 `rollout(None, 0)` 直接续接第一次的叶子，没有重跑前缀。禁止将它误判成重复模拟。
4. 评估和选模已有按局动态分配。只在测到启动或尾部占比足够大时改进进程结构。

## 数据和版本合同

新归档须保留全部帧字段，包括执行动作、DAgger 标签和候选软目标。
预编码特征签名不符时从归档内的原帧重新计算。
特征与等待抽样保持原来的顺序和数值类型。
训练器的已有命令行保持可用。
格式转换写新文件，原始档案默认保留。
C++ 增加协议能力时显式声明，Python 在旧二进制上回退或提示重编。

## 分批交付

精确项比较逐局统计和完整 DAgger 帧。
数据项比较加载张量、训练权重及 256 局学生评估。
近似项先做搜索一致率，再做 r8 的 128 局配对和原老师累计差距。
新增测试总量控制在 300 行以内。
每个验收数字先追加日记并提交，再继续下一批。
