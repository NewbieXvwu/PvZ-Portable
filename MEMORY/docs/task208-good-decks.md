# task208 候选与证据：重建评测卡组

**定位（2026-10-31 用户改）**：用户将亲自在游戏里选卡并录几局，**以后以他的卡组为准**。
本文档因此是「候选与证据」：每关给出候选卡组和老师（生产现行配置）从头打的胜率，
最终门禁 / 北极星卡组在用户卡组进来之前不定稿。用户录过的关，其卡组登记进
`scripts/pvz_tasks.py` 的 `USER_DECKS`，自动成为该关第一套。

废弃理由（用户判断）：门禁 / 北极星 / 训练现在用的卡组大多不是好解法，
基于它们的评测没有公信力。不保留旧列，不追求和旧曲线可比。

## 判据

1. **候选来源**：task105 导入库（`artifacts/task105/import/sha256/*/meta.json`）里
   GPT Pro 在 1.0× 下的胜利卡组，主族 `llmplay_decks_*`（扩卡组包）；
   **雾关只认 `fog_observation == human_v2` 遮挡下的胜利**。
   40 个普通选卡关（1–49，排除传送带关 5/10/15/20/25/30/35/40/45/50 与小游戏）。
   每关 1.0× 胜利卡组去重后的候选池 20–31 套（合计 1308 套），
   过完判据 2–3 后每关剩 2–23 套可用，取其中最多 3 套进表。
2. **常识剔除废卡**（任务设计层面的黑白名单，AGENTS.md §8.5 允许，不是手写策略）：
   没有蘑菇时的咖啡豆、无气球/蹦极/雾时的三叶草、只产钱的金盏花、黄金磁力菇、
   非水路上的海蘑菇、非夜/雾关的墓碑吞噬者、无铁桶铁门梯子时的磁力菇、
   泳池/雾缺睡莲或香蒲、屋顶缺花盆、持续输出不足 2 张、没有经济卡。
3. **必须回答这一关的威胁**（从 `pvz_constants.zombie_allowed_levels()` 解析）：
   雾 → 路灯花；气球 → 三叶草/仙人掌/香蒲；蹦极或投石车 → 叶子保护伞；
   铁门 → 大喷菇/忧郁菇；冰车或雪橇、巨人 → 窝瓜/土豆雷/火爆辣椒/坚果系。
4. **同一关 2–3 套思路不同**：任意两套至少差 3 张卡（经济 / 主力输出 / 应对方式不同）。
5. **证据 = 生产现行老师从头打的胜率**：deploy25 配置
   （`--rollout-policy dw4i_s1`，雾/屋顶/Boss 走 GPT 行为克隆先验 `gptbc_s1` + 屋顶叶值 `v5roof`，
   其余 r52；`--static-value value_branch1`；`--native-games --verify-samples 9 --student-candidates 2 --dagger-beta 1`；
   引擎 `artifacts/production/deploy20/pvz-portable`）。
   已有数据先用：task194 第 2 步 GPT 先验老师的 313 个 GPT 胜组（2 种子）、
   task202 的通关结果（`origin/teacheradv`，旧卡组 8 种子）。
   证据不够的关补测：**8 种子、nice 19、≤4 进程（与生产共享额度），不抢生产**。

**排序**（证据强度，不是先验偏好）：8 种子补测 ≥6/8 → 3–5/8 → task194 2 种子有胜 →
1–2/8 → 未测（按 GPT 胜局数）→ 8 种子 0/8 垫底。0/8 的卡组仍保留在表里，
因为「GPT 赢过、生产老师 0/8」本身就是要报给用户的结论（这类卡组是好的*玩家*解法、
但不是好的*老师*评测卡组）。
当前进度：120 套候选里 99 套已有 8 种子结果、4 套只有 task194 的 2 种子先验、
其余 17 套的 8 种子补测仍在排队（生产优先，nice 19 / ≤4 进程）。

## 旧卡组的两类毛病（task202 事实核对，生产老师 8 种子）

task202（`origin/teacheradv`）在**同一批 8 个种子**上对比了
`deck_for_level` 标准卡组与旧门禁 / 生产卡组（task202 的 ctrl 列，北极星当时用的那套）。
结论要分开说，不能笼统讲"旧卡组都输"：

1. **标准卡组在雾 / 屋顶是结构性废卡组**：0/8 的关 = 31, 32, 33, 34, 36, 37, 38, 39, 43, 44, 46, 47, 48, 49

   泳池关没有三线 / 高坚果 / 地刺）。这种局在动作层怎么改都救不回来，
   在它上面做诊断只会得到"卡组×地形不匹配"的一次性结论（AGENTS.md §8）。
2. **旧门禁卡组的问题不是"打不过"，而是没有区分度**：1.0× 下 40 个可选关里
   34 套 8/8，
   只有 6 关不到 8/8（L28 6/8, L29 6/8, L44 3/8, L46 6/8, L47 7/8, L49 7/8）。
   老师恒赢的格子对门禁 ≈ 常数，对学生进度也没有梯度可言；
   加上它们本身没有覆盖关卡威胁（三叶草 heldout 曾连续 9 轮否决晋升），
   拿它们当评测基座就是用户说的"没有公信力"。
