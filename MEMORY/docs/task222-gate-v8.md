- 面板 **41 个冒险任务 + 2 个留出监控**：day 8、night 8、pool 9（L29 两套用户卡组）、
  fog 8、roof 8。传送带/特殊关（5/10/15/20/25/30/35/40/45/50）不入选 —— 没有选卡。
- 8 份用户录制（L16/L18/L22/L28/L29×2/L33/L49）全部优先；其余关卡用 task208 第一套（★）。
  L28 老师验收 4/8、L29 两套 0/8，仍按用户决定保留；L22/L49 的用户卡组也没有按老师胜率筛。

  单臂 684 局在 4 units 实测 **163 秒**；生产三方（A/B/现任）约 8 分钟，仍落在原来 12–13 分钟
  的门禁窗口内（原门禁的搜索开销更高）。
- 倍率沿用原有阶梯机制：从 v5 既有阶梯按关卡热启动，再按同一 `next_panel` 规则
  （≥90% 升一档、≤10% 降一档、≤20% 或 roof 改波数终点）跑了 4 轮基线校准。
  **没有按关卡手调**；下表面板倍率就是校准后的初值。
- 基线（round_000052 学生，生产 gate 设置，首 look）：day 15.6%、night 64.6%、pool 39.8%、
  fog 5.2%、roof 14.6%。低胜率区已自动切到存活波数终点，不是全输噪声。
- 新鲜历史：`GATE_VERSION` 升到 8；`reconcile_gate_panel` 在面板版本从 v5 变 v8 时丢掉旧
  task key / rates / 楼梯状态。v8 结果不与 v5 轮次比较。

## 生成 / 刷新

唯一实现：`scripts/make_gate_v8_panel.py`。它扫描用户录制目录里的 `meta.json`
（`task.level` / `task.deck`），按关卡去重；有用户卡组的关卡不再用 task208；
没有用户卡组的关卡取 `scripts/pvz_tasks.GOOD_DECKS[level][0]`。同一关多份不同用户卡组
会生成多个任务（L29 现在是 `user1`/`user2`）。新增录制只需要重跑：

```bash
python3 scripts/make_gate_v8_panel.py \
  --user-root ~/PvZ-search/artifacts/student/frames_v2/human \
  --base-panel configs/gate_v8_panel.json \
  --out configs/gate_v8_panel.json
```

`--base-panel` 保留已校准的倍率/低胜率标记；新关卡用 task180 初值。`--check` 逐字节校验。
生成器只做结构校验（6–10 张不重复、地形覆盖：泳池/雾有睡莲或香蒲、屋顶有花盆；
升级植物所有权由 `profile_for_deck` 处理），**不读老师胜率**。
