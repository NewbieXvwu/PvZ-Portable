**这是决定性结果，且推翻了预登记的两个假设**：

1. A 的语料与 r11 逐字节同构成（source_rows 逐标签全等，总行数 16,982,931 = r11），配方逐字段
   一致、seed 相同。若训练确定，A 应复现 r11 的 heldout ≈166。实际 A = **124（−22pp）**——
   **训练运行本身（GPU 非确定性等）对 heldout 的 run-to-run 方差极大**。
2. 但 A 在标准卡组对照上与 r11 持平（172 vs 168， McNemar p≈0.5）——方差**不是全局的**，
   它**特定于扰动卡组的泛化行为**：全局 val_loss 只差 0.008（3.5853 vs 3.5927），holdout 上差 22pp。
3. 机制：扰动卡组特有植物（27 Blover、32 Cabbage-pult）只出现在冻结的 legacy d7p 族
   （4.3% 行数）里，模型对该行为的约束弱，每个训练 run 在这里"抽签"；r11 抽到了好签
   （166、170，两个独立种子块一致），r13/r14 抽到中签（145、151），A 抽到烂签（124）。
4. **r13/r14 的 heldout 否决因此大概率是训练抽签噪声，不是"某族数据被挤掉"**：r14 总体
   0.0 [−1.9,+1.9]、day/night/pool 全部持平，唯一否决项就是 heldout；r13 除 heldout 外
   pool 也显著（−5.7），拒得没那么冤。配对统计（192 对）：r13 −10.9pp [−18.4,−3.4] p=.003、
   r14 −9.9pp [−17.4,−2.4] p=.007、A −21.9pp [−29,−14] p≈1e-8、对照 A +2.1pp [−5.3,+9.4] p=.5。

对门禁含义（结构性）：**现役是被选拔出来的"好签"，且它的对局被永久固定为比较基准**
（v2/v3 每轮重评现役，但重评的是同一个固定模型）；候选每个都是新抽的签。在这个方差
水平上，heldout 区的 192 对配对 McNemar 会以可观的假阳性率持续否决合格候选——
r14 就是疑似受害者。这与 task73 的种子层赢家诅咒同构，只是换到了训练抽签层。

## 步骤 4：结论与方案建议（供主控裁定，未改生产）

### 结论

1. **"训练里哪一部分挤掉了泛化"的答案：没有哪一部分——数据构成基本没变（扰动族 4.48%→4.31%），
   变的是训练抽签的运气。** heldout（换卡组泛化）是训练里方差最大的行为维度：与 r11 完全同数据、
   同配方、同 seed 的重训（变体 A）在 heldout 上 124/192（r11：166），在标准卡组对照上 172/192（r11：168，持平）。
   行为方差特定于"含稀有植物（27 Blover、32 Cabbage-pult）卡组"的打法——这类信号只来自
   4.3% 的冻结 legacy d7p 族，约束弱，每个训练 run 在这里近似随机抽签。
2. **r13 / r14 的 heldout 否决大概率是这种抽签噪声**：r14 总体 0.0 [−1.9,+1.9]、
   day/night/pool 全持平，唯一否决项是 heldout——疑似错杀。r13 另有 pool −5.7 与总体 −3.3，
   拒绝本身不冤，但 heldout 的 −6.0 也未必是真退步。
3. **结构性偏差（第二次赢家诅咒，这次在训练抽签层）**：现役是选拔出来的好签，其模型与
   对局被永久固定为基准；候选每轮都是新抽的签。heldout 区 192 对的 McNemar 否决在这种方差
   下会持续假阳性——r11 之后 6–11 轮连拒的旧谜题在 v2/v3 新种子下换了机制继续存在。
4. 32(Cabbage-pult) 的回避在 r13/r14 的翻转局里一致出现（少种 9.5–16.6 株/局），与
   A 的烂签行为同向——它是"抽签抽得差"的表现，而不是某个数据族被删掉的证据。

### 方案建议（按成本从低到高，主控定）

1. **门禁层：heldout 区否决阈值去噪。** 用实测的训练抽签方差（本任务 4 个样本：
   r11 166/170、r13 145、r14 151、A 124、B 65；完整样本与修订见文末追加段）重校 heldout 区：例如要求"候选在该区
   对现役的配对退步超过 max(3pp, 2×抽签σ)"，或 heldout 区不做 McNemar 单点否决、
   改为"连续两个候选在同一区显著退步才否决"（r13+r14 都挂恰好会触发，A/B 数据说明
   这仍可能是噪声，故更推荐 σ 校准而非连击规则）。
2. **训练层（更根本）：压小稀有行为的抽签方差。** 两个候选手段，都需要小实验验证：
   a. **d7p 族加权**（即变体 B 的做法推广：给含稀有植物的族 1.5–2× 权重）——若 B 的
      heldout 显著好于同分布的 A（124）与 r13/r14（145/151），则有效；否则放弃。
   b. **扩大稀有植物卡组的采集覆盖**：把扰动卡组族（d7p 式换卡）重新加回课程轮转
      （哪怕每轮保底 1–2 组），让 27/32 的行为有新鲜信号，而不是靠冻结的 76 万行。
      这同时直接回应任务书"扰动卡组族保底份额"的方向。
3. **评估层（诊断用）**：晋升候选时顺手在 heldout 上对同一候选做 2 次训练重启
   （或对现役做一次同数据重训）来估计当轮的抽签方差，把方差写进门禁证据里。
   成本：每次重训 ≈45 分钟 + 192 局 ≈4 分钟。
4. **不建议**：回滚 r13/r14 的否决结果（门禁按规则行事，历史结论保持）；或调低
   非劣界（会同时削弱拦截真退步的能力——task73 实测拦截力与样本量无关、很硬）。

## 主控追加（2026-10-26 04:35）：变体 C / D

    若对照也崩 ⇒ 微调整体伤害。
- **D（从头训练方差）**：r11 配方原样（348 标签、12 epochs、lr 0.002），仅 seed 1→2、1→3，各训一次。
  - H-D：同配方三种子（seed1=166、seed2、seed3）heldout 极差 ≥30pp，样本 std ≈15–25pp；
    A（seed1 重跑、不同标签集）作旁证。
  - 用途：若 std 在此量级，门禁 heldout 区固定 192 对 McNemar 假阳性率高，需随机性口径。
- 检验方法：与 A/B 同脚本（task84_ablation_eval.py，MODELS 增 c/d2/d3），配对 McNemar +
  Newcombe method 10；D 的 σ = 三个同配方种子 heldout 胜率的样本 std（n=3，只报极差与 std）。
- 约束：GPU 一次只训一个，qc 训练优先（qc round16 训练已于 03:50 结束，现空闲）。

### 追加结果与最终建议（C/D 完成，2026-10-26）

H-C 被否、H-D 部分成立（见上）。合并全部消融样本，heldout（day_l7_eval_d7p_holdout1，192 对）上的
从头训练 draw：

| 训练语料 | draw |
|---|---|
| r11 语料（348 标签） | r11=166、A=124（同 seed 重跑）、D2=169、D3=168 —— 典型簇 166–169，尾部 124 |
| r13 语料（380 标签） | r13=145；B（d7p×3 加权）=65；C（从 r11 续训）=135 |
| r14 语料 | r14=151 |
| r15 语料 | holdout1=65、holdout2=0（门禁记录） |

**对主控两问的回答：**

1. **管线：续训不可选，多种子挑选可行但挑选指标必须避开 heldout。** C 证明从现役续训
   （lr/4、3 epoch）heldout 仍掉 16pp 且显著（135 vs 166）——续训保不住 heldout 区，
   且逐轮续训会累积漂移、毁掉与历史证据的可比性。从头训练 + 挑选则要防两件事：
   (a) **不能按 heldout 挑**（在检验集上选择 = 赢家诅咒，heldout 的独立性就毁了）；
   (b) 挑选指标用训练侧信号——但注意全局 val_loss 检测不到烂签（A 的 val_loss 3.5853
   好于 r11 的 3.5927），需要 **d7p 卡组的小验证任务**（训练族内部数据，不碰 heldout 的 192 种子）
   在训完即筛掉灾难 draw。成本：每候选多评 ~192 局 ≈2 分钟。
2. **门禁 heldout 区需要随机性口径，推荐复制规则而非放大阈值。** 同配方 draw 的样本 std ≈22pp，
   但其中典型 draw 彼此仅差 3pp、与现役不可区分——固定 192 对 McNemar 对约 1/4 概率的灾难 draw
   必然否决。两个方案：
   - **推荐：复制制**——heldout 首次显著退步后，候选重训 1 个新种子再评；两次都显著退步才否决。
     r15（65、0/192）这类极端崩盘一次即拒不受影响；r13（145）/r14（151）这类 −10~−15pp 的
     边缘退步获得重抽机会。成本：被否轮次多训一次（≈45–75 分钟）。
   - 不推荐：非劣界放宽到 2σ≈30pp——会同时放过真退步，且对 0/192 型崩盘毫无必要。
   - 配套：现役是对抽签分布的**单点实现**（r11 的 166 恰在典型簇内，不算幸运得离谱），
     否决规则应按"候选 draw 分布 vs 现役实现"来定，复制制是它的最小近似。

**保留意见（两解释暂无法分离）**：r13/r14/r15 语料的 draw（145/151/65）全部 ≤151，而 r11 语料
3/4 ≥166——"新族语料平均压低 heldout"与"抽签运气"两种解释并存（B/C 都基于 r13 语料，
65/135 无法归因）。D 系列只量化了 r11 配方；要分离需用 r13 语料再抽 2–3 个种子（未做，
每个 ≈1 小时）。当前证据下倾向两者叠加：语料效应 ~−10pp + 尾部事件。

**对步骤 4 旧建议的修订**：旧建议 1 的"σ 校准阈值"细化为上面的复制制；旧建议 2a
（d7p 加权）被 B 否决（65/192，比不加权更差），**放弃**；旧建议 2b（扰动卡组回课程轮转）
仍然成立，且是唯一可能提高 heldout 均值的手段；旧建议 3（评估层诊断）由 D 系列直接完成，
数字如上。

### 结果（r13s2 / r13s3）

| 变体 | heldout | 对照 | 备注 |
|---|---|---|---|
| r13 本尊（seed1） | 145/192 | — | 门禁历史 |
| r13s2（seed2） | **188/192**（4 翻 26 得，+11.5pp，p≈2e-4 **优于 r11**） | 162/192（持平） | 全部样本中最好 |
| r13s3（seed3） | **116/192**（63 翻 13 得，−26pp，p≈1e-8） | 168/192（持平） | 接近 A 的尾部 |

**判定：落在主控规则的中间档，照实报告。** 既非"两个 ≥160"也非"两个 ≤152"：

1. **语料效应被削弱**：r13 语料从零训练的 3 个 draw = {145, 188, 116}（均值 149.7、std 36），
   r11 语料 4 个 draw = {166, 124, 169, 168}（均值 156.8、std 22）——均值差在 n=3/4 下不可分辨，
   两个语料的 draw 分布都很宽。r13 语料既能抽出全场最好（188）也能抽出接近最差（116）。
2. **全局训练指标对好坏签完全盲**：9 个 draw 的 val_loss（3.585–3.634，极差 1.3%）与 heldout
   （65–188）不相关甚至略负相关——heldout 188 的 r13s2 val_loss 全场最差（3.6339），heldout 65 的
   r15 val_loss 比 r11 还好。type_acc/plant_recall/packet_acc/cell_acc 同样平坦（各 ±1% 内）。
   **"多种子挑选"若用现有标量指标等于盲选**；可行的挑选信号只剩针对性探针：d7p 卡组小验证任务
   （未测）或 2–3 个非 heldout 门禁任务的小规模评估（每候选 ≈2–4 分钟，192–384 局）。
3. **门禁复制制升级为双向必需**：坏签会被假否决（r14 型），好签也可能只是抽得好（r13s2 的 188
   未必可复现）——若把极端 draw 提拔为现役，下一轮的比较基准就是一个未复现的极端值。建议
   晋升与否决对称地要求复制（候选在 heldout 显著更好时同样重训一次复评，两次都好才晋升）。
4. **上限被证实**：r13 语料的 seed2 draw（188）比 r11 语料 4 个 draw 的任何值都高 19pp 以上——
   多种子训练 + 有效挑选的潜在收益是真实的，不只是避免假否决。
