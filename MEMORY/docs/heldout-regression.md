   （multiplier_panel.json 逐任务核对），q 只是新种子段。真正含扰动卡组的训练数据是 **legacy

2. 扰动族占比只从 4.48% 稀释到 4.31%（legacy 主力另带 1.5 权重，有效占比 3.19%→3.08%）。

## 步骤 2：heldout 对局级取证

脚本 scripts/task84_heldout_forensics.py。门禁 v2 评估里现役 r11 与候选在同批新种子上双侧重跑
（r13 块 [31024,32560)、r14 块 [33200,34736)），天然成对。主任务 day_l7_eval_d7p_holdout1
（deck [0,1,2,27,5,32,3]，192 种子）：

| | r13 | r14 |
|---|---|---|
| r11（现役） | 166/192 | 170/192 |
| 候选 | 145/192 | 151/192 |
| 翻转（r11 赢→候选输） | 38 | 37 |
| 反向（候选赢→r11 输） | 17 | 18 |
| 候选在翻转局的死亡波次中位 | 28（p25=18） | 20（p25=15） |
| 候选全体的死亡波次中位 | 27（p25=15） | 21（p25=15） |

**植物配比（每局平均株数，候选 − 现役）**：

- r13 翻转局：**27(Blover 三叶草) −5.03、32(Cabbage-pult 卷心菜投手) −9.47、1(向日葵) +3.32**；
  全种子：27 −5.13、32 +1.09、1 +1.11。
- r14 翻转局：**32 −16.62、1 +6.70**（27 反而 +0.65）；全种子：1 +3.23、27 +4.11、32 −3.35。
- 对照 day_l7_eval_d7（标准卡组 [0,1,2,3,4,5,7]）：r13 净 −2、r14 净 +2，配比变化小
  （0(豌豆)+3.2 / −0.56），无退步。day_l9_eval_d7p_holdout1 两边都在地板（0–2/192），无信息。

**定位结论**：退步集中在扰动卡组特有植物上——32（Cabbage-pult）是该卡组的主火力，r13/r14
一致性少种（翻转局少 9.5–16.6 株/局，阳光转去向日葵），中盘（15–20 波，比 r11 的 p25=29
早 10+ 波）被破防。而**全部训练族的卡组里没有任何一个含 32 或 27**（multiplier_panel.json
逐任务核对：d7/n10/f8/fog_user/p9k 均不含；roof_r7 含 32 但只有 0.06–0.09% 行数）——学生对该
卡组的唯一训练信号就是那 760k 行冻结的 legacy d7p 扰动族数据（4.3%，逐轮被稀释）。r11 →
r13/r14 期间唯一的系统性变化就是稀释 + 从头训练对语料微小变化的敏感性（r13 的全局 val_loss
离群说明这种敏感性真实存在）。

## 步骤 3：消融（预登记，2026-10-25）

配方 = r13 recipe.json 逐字段复制，只改 labels / label_weight / out / cache_dir，训练命令与管线
同一入口（train_rollout_policy.py --recipe，epochs 12、AdamW lr 0.002、seed 1、precompute_workers
8、cuda）。变体 recipe 已生成（artifacts/task84/variant_{a,b}/recipe.json，git 外）：

- **A（去新族）**：labels = r11 的 348 个标签（= 去掉 32 个 r12+ 首次采集的 c-label：fog_user、
  roof、demo 起点、p26–p29、n19/n20、各新倍率档）。因 recipe 超参与 r11 完全一致且训练 seed
  固定，**A 同时是管线确定性的对照**：若 A 复现 r11 的 heldout 表现（≈166/192），则「语料构成→
  heldout 退步」因果成立；若明显偏离，则轮间结果有可观训练噪声，「连续两轮退步」的证据力要重估。
  预期（H-构成）：≈166/192。
- **B（保新族，扶扰动族）**：labels = r13 全部 380，28 个 legacy d7p 标签 label_weight 1.0→**1.5**
  （与 legacy 主力同权；有效占比 3.08%→4.5%）。原任务书的「恢复到 r11 占比」实测只差 ×1.04
  （4.48%→4.31%），等于空跑，故按「与 legacy 同权」预登记，倍率写死在此。预期（H-稀释）：
  翻转局显著减少、heldout ≥160/192；若无效，说明稀释不是主因，问题在表征/状态覆盖而非采样配比。

评估：两个变体各在 r13 门禁的 heldout 192 种子（31408–31599）上与 r11 配对（评估参数与门禁
契约一致：deploy4 引擎、v5 value、arms=fast、β=0；r11 的对局直接复用 r13 评估目录，确定性逐位
可比）。每变体 192 局，2 游戏进程内约 3.5 分钟。
