## 判读（供主控定示范顺序）

1. **屋顶 L42–49 全部 0/16，老师完全不会打**：L42/44/46/48/49 与 L43 的大部分输局死于第 3–7 波（开局经济/布防阶段即崩），破防以普通+路障海量和铁桶为主，L46/L47 另有投石车、L43/L45 有梯子。这是最大的示范缺口——老师没有屋顶关的可用经验，用户示范应**优先屋顶**（L42 起步，L43/L44 次之；L45 蹦极传送带机制不同、能撑到 14 波以后，可稍后；L47 有 6 局撑过 29 波，说明老师偶尔能开局，缺口在终盘大波）。
2. **雾夜 qc 默认卡组 L36–39 全 0/16 且都在第 7–9 波崩**：破防里有稳定的**矿工僵尸**（L36 达 11 只）——默认卡组没有应对水路后方偷袭的手段，属于卡组×机制结构性问题；同关换第二套卡组后 L36–38 达 15–16/16。**这三格先换卡组即可，不必急着要示范**。
3. **雾夜 L39 两套卡组都全灭**：用户卡组能打到第 16–29 波但**气球僵尸 21 只破防**——两套卡组都没有对空手段（无三线射手/香蒲对空位/卷心菜投手代价下不可及）。要救 L39 需要含对空的卡组（如香蒲已在 qc 卡组却仍 0/16，说明 qc 卡组在 L39 的问题不止对空）或用户示范直接教，建议与屋顶一起排。
4. 用户卡组 L36–38 的 15–16/16 说明该卡组+老师已是接近通关的状态，可作为这三格的"老师水平"基线，无需示范。
