## 项目背景（读这一节就够理解问题）

- **任务**：让 AI 打通《植物大战僵尸》冒险模式 50 关，并能泛化到没见过的卡组。
  - 关卡分五种地形：白天、夜间、泳池、雾、屋顶。
  - 每局玩家从约 40 种植物里选 6–10 张卡组成卡组。
  - 我们自己移植了游戏引擎（C++），可以无界面快速对局。
- **老师**：基于搜索的老师，在每个决策点对候选动作做多次续走（rollout），用一个小策略网络快速走完后续，再加一个价值网估叶子。
  - 一局里根节点决策与续走网络调用之比约 1 : 132。
- **学生**：模仿老师的策略网络，用 DAgger 方式迭代。
  - 学生自己打，老师在学生走到的状态上给标签。
  - 学生同时也是老师续走用的小网络。
- **学生网络现状**：
  - 6×10 格子的 CNN，宽 64，约 18 万参数；
  - 三个输出头：种还是等、选哪张卡、种哪一格；
  - 训练数据约 2300 万行（状态, 老师动作）；
  - 推理在 CPU 上用 C++，单次约 150 µs。
- **候选新结构（v3）**：实体 token + 带关系偏置的多头注意力（关系偏置包括种类对、行差、列差、同格）+ 指针头。
  - C++ 单次前向：宽 128、2 层约 4.3 ms；宽 192、4 层约 14 ms。
  - 计划只用在老师根节点（每小时局数约降 4%），续走仍用 CNN。
- **训练流程**：
  - 每轮采 768 局；新数据加入一个大的累积训练包；
  - 每轮用 A、B 两个配方各训 2 个候选；
  - 用一组固定面板挑选最好的候选；
  - 再过门禁：与现任学生配对对局，总体置信区间加上“每个地形都不能显著退步”的否决。
- **已知的本地实验结果（这些是我们自己的证据，请拿来对照文献）**：
  - **加宽**：同语料把 CNN 加宽到 128，白天早期关卡变好，但陌生卡组从 60.0% 降到 53.8%，夜间从 51.4% 降到 42.6%。
  - **按地形分专家**（E3，约 435 万行，五地形）：每个地形单独训的 64 宽网络，在本地形只比联合网络高 1.8–5.8 个百分点，在陌生卡组上低 4–20 个百分点；专家之间几乎不迁移。
  - **早期实体注意力原型**：在很小的数据上（152 局）与 CNN 打平（91.0% 对 91.3%）。当时有实现问题：卡包混进了均值池化。
  - **标签审计**：等价动作之间的标签矛盾只占 0.05%。
  - **数据构成**：约 60% 的行来自课程开始前的历史 DAgger，其中一关（L7）占 47%；82% 的行来自 32 套默认卡组，其中一套就占 45%；随机卡组只占 0.5%。
  - **挑选与门禁的口径**：挑选按平均胜率选候选，门禁按“最差地形不能显著退步”否决。“补弱地形”的 B 配方几乎从没被挑中过。

### Q1. 在约 1000 万–3000 万样本的模仿学习 / 行为克隆里，实体 / Transformer 编码器相对 CNN 的数据效率如何？

这是我们最大的不确定性。上一份调研没找到同规模的直接对照，只是从 ViT / DeiT 外推。请找：
- 游戏或决策任务中，实体 / 集合编码（entity encoder、Set Transformer、Deep Sets、关系偏置注意力）与卷积 / 空间编码的**同数据量对照**，例如：
  - AlphaStar 的消融；
  - NetHack 的行为克隆与缩放律（Tuyls et al. 2023 等）；
  - Hearthstone、Slay the Spire、星际 / Dota 的行为克隆；
  - 网格环境（Crafter、MiniHack、Procgen）上的结构对比；
  - 近年的决策 Transformer、Gato 小规模版本。
- 数据量多大时注意力开始超过 CNN？有没有“小数据时 CNN 更好、大数据时反超”的交叉点？

关键词：entity transformer vs CNN behavior cloning data efficiency, relational inductive bias, set-based observation encoder games, scaling laws imitation learning NetHack, inductive bias sample efficiency small data。

### Q2. 小规模行为克隆 / 强化学习中，MoE 与条件化（FiLM、adapter、任务嵌入）对没见过的配置（分布外）是帮还是伤？

我们的本地证据是：分专家伤了陌生卡组，加宽也伤。请找：
- 多任务强化学习 / 模仿学习中 MoE 的分布外泛化结果，包括 Soft MoE（Obando-Ceron 2024）、MOORE、CARE、soft modularization；
- FiLM / 任务条件化在多环境强化学习中的泛化证据；
- 小数据下路由塌缩的研究；
- “容量增加伤分布外泛化”的研究：过参数化、捷径学习，以及加宽后分布外下降的报告。

### Q5. 卡牌 / 组合类游戏中，策略如何泛化到没见过的卡组或组合？
