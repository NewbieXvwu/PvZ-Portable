# DAgger 轮次增加后的学生退化审计（task15）

**结论：扩集退化在两个新训练种子中均复现；固定epoch带来的优化预算/余弦调度漂移是得到支持的可干预因素，恢复旧倍率配比也能改善。** D30六档平均772.42胜/1024，完整D35降至727.92（−4.35个百分点）；保留全部D35、把步数及余弦预算固定为D30的42,456步，恢复至772.42，S−F为+4.35个百分点，整簇95%CI[+2.97,+5.75]，Holm p=1.52428e−9。14个全新模型、两个训练种子、每模型六档各1024局，共86,016局全部完成；执行验收、独立统计和33,919份源档案身份复核通过。

**建议训练集构成：采用S——完整D35的68个冻结采集标签，保留新旧轮次的自标签、老师纠正和高/低spread行，沿用原wait抽样与packet/spread/cell-soft权重，不追加倍率/新近权重；在原12epoch、cosine命令上加`--max-steps 42456`。** 这同时限定总更新与余弦长度，实际在第10个epoch中途结束，不能用“改成10个完整epoch”代替。与F相比少18.78%更新，两个种子的全部12个档位胜局数都提高。部署默认、现役模型及正式队列未改。

恢复D30条件倍率比例的T也有支持（T−F +3.28个百分点，95%CI[+1.90,+4.67]）；可以作为单独备选，但T+S未跑，不推荐把两者收益相加。全面均衡倍率M下降13.56个百分点；只保留新增轮次纠正/高spread行并恢复权重的I下降41.71个百分点，且比匹配随机控制R低36.39个百分点。因此本次证据不支持仅凭新轮次自标签比例高就删除这些行。

## 各假设能解释什么

- **H1 倍率配比：部分支持。** 固定D35行、划分、步数及各packet×soft资格层总权重后，T两种子均改善（+3.19/+3.37pp），支持恢复旧条件配比这一干预。M均衡所有观察到的倍率则两种子均变差（−9.34/−17.77pp）；T最大行倍率1.394，M为23.142，不能把“恢复旧分布”和“大幅均衡”合并为同一结论。尚不能将T收益解释为历史退化的独立归因份额。
- **H2 自标签稀释：本次筛选补救被否定。** I比等数量、分层且最终权重分布匹配的R低36.39pp；R本身也比F低5.32pp。源权重审计中各损失头的纠正系数占比并未下降。当前证据支持保留普通自标签覆盖，而不支持这套“纠正或高spread”筛选。I同时选择两类信息、改变训练条件分布并集中权重，不能据此宣布老师纠正本身有害，或排除所有其他标签混合机制。I/R均通过置零及重加权保持原行顺序/步数，并非删行后重新按12epoch训练。
- **H3 训练种子方差：存在，但不能单独解释本次一致退化。** B、F两种子六档均值差分别3.69、3.21pp；B−F在配对种子上仍同向为+4.10/+4.59pp。S种子差1.38pp且相对F两种子都提高。这里只说明这两个初始化中的一致方向，两个种子不足以估计初始化总体的不确定性，历史零散种子未混入本次检验。
- **H4 预算/调度漂移：支持联合因素，其他漂移仍未隔离。** F多了23.12%更新；S固定为42,456步并同步缩短余弦长度，S−F为+5.26/+3.43pp，六档平均恢复到B的点估计。不能把收益只归于“多训练了几步”，也不能据此把旧训练/验证重划分等其他变化全部排除。F→S最终验证loss为3.256305→3.257742（seed1）、3.258879→3.259659（seed2），loss略高而政策更强；本研究没有按验证loss挑epoch。

S与B平均恰同为772.42胜/1024，档位取舍不同：S−B在z15–z17为−4.69/−3.47/−1.51pp，在z18–z20为+1.51/+5.13/+3.03pp。这是描述性比较，B−S不在主要检验族中，不能声称二者等价或S逐档优于B。S−F的平均逐档收益为+3.42/+1.76/+3.32/+5.27/+7.42/+4.88pp，两个种子各档胜局数全部提高，故优先推荐S作为当前完整D35的预算配方。T为独立备选，不宣称S显著优于T，也不外推为优于未另训的历史早期×1.5或现役v32。
