## 2. 分歧逐条判断

| # | 分歧 | 判定 | 依据（报告内出处 + 本地证据） |
|---|---|---|---|
| 1 | **挑选口径（Q3）**：Gemini 主张改成最差地形优先 | **三份对，Gemini 错** | DoReMi 优化的是**数据混合权重**，报告的成功指标是平均下游 +6.5 pp / 2.6× 步数（Grok、GPT-Normal、GPT-DeepResearch 同引），不是候选间 minimax；AlphaGo Zero 的 55% 是**全局**晋升门槛，AlphaZero 取消了迭代门（Grok 引 Nature 2017；GPT-Normal/DR 引 ELF OpenGo Table S1）；DomainBed 的教训是"选择协议必须与部署一致"——我们的部署标准是"总体不显著退步 + 分地形不显著退步"，纯 min 恰好错位，还会被屋顶 0/128 地板与雾的高方差主宰（本地 E3）；B 配方从未被挑中说明挑选与门禁不同构（task136），不是 min 的证据 |
| 2 | **随机卡组配额（Q5）**：Gemini 主张"0.2%→25%" | **三份对，Gemini 的数字不成立** | deploy17/18 已是四类采集各 25%、卡组池 54（+38）；"0.2%"是行份额，不是局配额；Procgen 的 500 关是**测量难度点**，合上缺口要数千至约 1 万关（Grok 引 Cobbe 2020）；更硬的是教师 14.6%（task129 54 套 × 8 局 = 432 局 63 胜），task154 显示 94.5% 的决策所有候选都输 → 只加局数得到常数标签（Grok、GPT-Normal、DR 同向） |
| 3 | **分歧采样的效应量（Q4）**：Gemini 称剪枝可净化"约六成标签噪声"、"消除 97% 冗余" | **Grok/DR 对，Gemini 的数值无出处** | KataGo 剪枝的单项消融是约 **1.25×** Elo（Grok 引 arXiv:1902.10565v5）；KataGo 的收获是整套技巧相对 ELF 的约 50× GPU 年，不能拆给单项；本地 E8：旧/新教师搜索点一致 0.440、等价动作矛盾 0.05%，推翻里约六成是价值噪声——97% 标签等于学生动作是 DAgger 的固有分布，不是可删冗余 |
| 4 | **Q6 事实**：Gemini 把 500k 归 AlphaZero、τ=5 标"已核实" | **Grok/GPT-Normal/DR 对** | 500k 局见 AlphaGo Zero 2017 Methods（"most recent 500,000 games"）；AlphaZero 原文未指定（ELF Table S1：AGZ=500k、AZ=`?`）；温度采样见 Arivazhagan 2019：`p_l ∝ p_l^(1/T)`，T=5 为平衡设定，T=100 近均匀（Grok 附 BLEU 表） |
| 5 | **FiLM 置信度（Q2）**：Gemini 称"最优、高" | **三份对** | CARE 里 FiLM 已拿走大部分多任务增益，但任务全在训练集内（Grok：MT10 CARE 0.84 vs FiLM 0.75）；未见卡组没有条件化证据；本地 E3 未见卡组专家 0.0656–0.2252 全线低于联合 |
| 6 | **Q1 置信度**：Gemini 对"无交叉点"与"v3 会赢"都给"高" | **采三份的分级** | 三份都拆成"没有交叉点文献=高"与"v3 是否胜出=中/低"；Gemini 的"CNN 在千万级收敛快且稳定"没有给出处 |

## 3. 对 `task160-b-literature.md` 的纠正清单

| 旧调研原文（§12 等） | 纠正 | 依据（报告内） |
|---|---|---|
| "AlphaZero 回放窗口约 50 万局"（标未核实） | **归属错**：500k 局属 **AlphaGo Zero**（2017 Methods，均匀抽最近 50 万局）；**AlphaZero 未指定**（ELF OpenGo Table S1：AZ=`?`，ELF 复现也用 AGZ 的 500k）；55% 晋升同属 AGZ，AZ 取消 | Grok Q6；GPT-Normal Q6；GPT-DeepResearch Q6 |
| "温度采样 τ=5，Johnson et al. 2016……用 α>1 提高低资源权重" | **出处与方向都错**：温度采样属 **Arivazhagan et al. 2019**，`p_l ∝ p_l^(1/T)`；T=5 平衡、T=100≈均匀；上调低资源对应指数 **1/T<1**，旧文 `α>1` 反了；Johnson et al. **2017** 原文没有温度 | Grok Q6（附 En→Any BLEU：T=1 6.24、T=5 12.75、T=100 12.87）；GPT-Normal Q6 第 10 条 |
| "AlphaStar 1.39 亿参数（二手，未逐字核实）" | **已核实**：Nature 2019 正文 139M 权重、推理仅 55M；971k 局监督 + 16k 局微调；32 块三代 TPU × 44 天 | Grok、GPT-Normal、DR 一致 |
| "AlphaGo 24%/2 µs 未逐字核实" | **已核实且更精确**：rollout **24.2% / 2 µs**；SL policy **57.0% / 约 3 ms**（Nature 2016 p.485） | Grok、GPT-Normal、Gemini、DR 一致 |
| "KataGo 具体回放窗口、样本权重公式未核实" | **拆开**：论文有窗口，250k → 约 2200 万，**单位是样本不是局**、窗内均匀；**没有跨版本固定窗口**（脚本 `taper-window-scale`/`SHUFFLE_KEEPROWS` 只是配置）；采样加权是 g170 起的 **policy surprise weighting**：约一半均匀 + 一半按 KL(搜索目标‖先验)，官方配置 `policySurpriseDataWeight=0.5`；不要把辅助损失系数（如 `w_opp=0.15`、软策略头 T=4/8×）当成采样权重 | Grok Q6；GPT-DeepResearch Q6；GPT-Normal Q6 第 4 条 |
| "CARE 细节未读" | **全称**：*Contextual Attention-based Representation learning*；题目是 *Multi-Task RL with Context-based Representations*；Meta-World MT10/MT50，含未见环境实验 | Grok、GPT-Normal、DR |
| "DoReMi / 温度采样可信度高" | DoReMi 是**语言模型配比**、报告平均 +6.5 pp / 2.6×；不是 checkpoint minimax；本地 E1/E13（降权/封顶/温度）三次判负，不能反向借用 | Grok、GPT-Normal、DR；决策备忘 §11.10–§11.11 |
| "Soft MoE 是唯一有正面缩放证据的选项" | 成立但限**分布内**：Atari 8 专家约 +20%，推理要过全部专家；不覆盖未见卡组 | Grok Q2；GPT-DeepResearch Q2 |
| "Leela Zero 的回放窗口/采样"（未核实） | **仍查不到**单一常数，继续标"查不到"，不与 Leela Chess Zero 混用 | Grok、GPT-Normal |
| "Transformer 在 10M–30M 行不如/等于 CNN" | **仍查不到**直接对照，维持外推标注 | 四份一致 |
| "MoE 对 OOD 帮还是伤" | **仍无 RL/BC 直接测量**；GMoE 是视觉域；本地 E3 只否决"五地形硬专家"这一种配置 | 四份一致 |
| "宽 128 伤未知卡组/夜间 60.0→53.8、51.4→42.6" | 是**本地 task23 证据**，不是文献；且 E3 joint128 陌生卡组 cell_acc 0.3150 > joint64 0.2699（不同口径）→ 准确表述是"加宽没有稳定兑付真打收益" | 决策备忘 §11.9；GPT-Normal Q6 第 12 条 |
