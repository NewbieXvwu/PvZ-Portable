独立16未来确认找到3项Holm校正后p≤0.05且均值改善的候选/指标。同一根的各候选共享世界与搜索噪声种子；跨观测臂只配对reset seed，不把臂间差异解释为严格同未来的因果效应。

v4排序对照为正式的2500tick学生续走叶值；真实终局路径从候选立即接冻结搜索老师。另报老师路径2500tick附近的v4值，区分续走分布与估值误差。所有叶中途已终局时的真值评分与真实非终局v4排序对分开报告。

成对一致率分胜率差≥1/3、平均末波差≥1、平均终tick差≥600三把尺子；另报全部严格不等对。真值平局不计，v4平局计半分。95%区间按关卡/reset seed整组bootstrap，human/xray和同局各根一起重采样，不能拿候选对数充当独立样本。筛查只有3未来，其最优存在选择偏差；显著改进只认新16未来、配对符号检验及全家族Holm校正。末波提高不等同存活时间变长。

CPU计量14.100小时，另保守计入480秒未独立计量的准备/测试/报告开销，共14.233小时；自有产物0.154GB。四槽结构与实际进程采样限额均在run回执。
