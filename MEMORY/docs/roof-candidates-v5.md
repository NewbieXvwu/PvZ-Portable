## 一句话结论

**候选遗漏已经从"最大缺口"降级为"行为层的最大缺口"，但它不是胜率缺口。**
把每个合法植物格都放进候选（`all_plants`）能把老师的终局中位波次从 4 拉到 25、
推翻率从 6.5% 拉到 22.9%、搜索决策里最优叶值低于 0.02 门槛的比例从 51% 降到 6%——
**但胜局只从 0/32 变成 4/32（p=0.125），L43 仍是 0/32。**
胜负卡在第 24–30 波：死亡时棋盘已满（45 格里 43 株植物），而 r7 卡组里能持续输出的只有
卷心菜投手一张（8.2 株/局），咖啡豆在无蘑菇卡组里 0 次种植。

## 方法与合规

- **输入冻结**：build4 引擎、现役 round_11 学生、v5 叶值、branch1 静态网各复制一份进本工作树
  ignored 目录并逐文件 SHA256 核验（另留 v4 作叶值对照）。L41–L49 的 r7 卡组用真实引擎
  reset 核对解锁与警告，全部通过。
- **诊断包装只读**：三个臂共用同一份 `search_play` 决策路径，只在诊断 worker 里包
  `_halving_choice` 把候选集换成扩展集；生产默认与开关未改。
- **扰动检验**：在 L42 seed45000000 的第 0 个搜索根插 2 个终局 rollout 后，整局仍与存档逐字段
  一致（STATE_HASH `a4334811f7014e54`、367 决策、19433 tick、末波 7）。探针不改变后续对局。
- **配对**：同一批 32 个固定评估种子（45000000–45000031），三臂各跑一遍，逐种子配对。
  全部终局，无动作上限截断。
- **覆盖统计的重建口径**：生产候选集 = 每张可负担卡片的静态最优格 + 学生自己的动作 + 等待
  （`per_card=1`）。学生额外加的 2 个候选没有逐决策落盘，所以重建集是生产集的**子集**，
  因此"最优格被漏掉"的比例是**保守上界**，不是精确值。
- **终局真值**：冻结根上每个合法植物/铲子/等待各 8 个终局未来，续走用冻结的贪心学生
  （C++ ROLLOUT `until_tick=0`），与 task46 的"老师续走 + 2 未来"协议不同，只作历史参照。

## 结果 2：候选覆盖（production 自己的 trace）

| 指标 | L42 | L43 |
|---|---|---|
| 搜索决策数 | 1528 | 2546 |
| 合法植物格/决策（均值） | 27.4 | 18.8 |
| 生产候选/决策（均值） | 5.1 | 4.8 |
| 最优叶值格**不在**生产候选里 | 39.0% | 37.4% |
| 遗漏 regret > 0.02（推翻门槛） | 7.3% | 13.2% |
| 最优叶值 < 0.02 的决策（推翻不可能触发） | 51% | 16% |
| 推翻率（override / 搜索决策） | 6.5% | 17.0% |

生产每决策只评估约 5 个动作，而合法格有 19–27 个；被漏掉的正是"同一张卡的别的格子"。
L42 有一半的搜索决策里**所有**候选的叶值都在 0.02 门槛之下——搜索只能把决定权交回学生。

## 结果 3：补全候选改变了什么

- 终局中位波次 4 → 25（L42）、6 → 24（L43）；每局植物 33.5 → 115.7；搜索决策 290 → 861。
- 推翻率 6.5% → 22.9%（L42）；最优叶值中位 **0.019 → 0.612**；低于门槛的决策 51% → 6%。
  也就是说：不是叶值网突然变准了，而是**候选里终于有值得种的动作**。
- 胜局 0 → 4/32（p=0.125）。**行为变了，胜负没变。**

## 结果 4：含铲子臂反而更差

`all_legal` 每局铲 15.3（L42）/18.3（L43）次，每决策评估 44 个候选，终局中位波次只有 9–10，
明显低于 `all_plants` 的 24–25。候选越多、halving 第一轮每候选只有一个未来，
证据越薄、选择越噪；加上铲子能拆掉自己刚种的植物，动作空间扩大在这里是**负收益**。
→ 候选扩展只应加"植物格"，不应顺手把铲子也放开。

## 结果 5：后半程的瓶颈在卡组，不在候选

死亡时刻（最后一个决策）的棋盘构成，L42 `all_plants` 平均：

| 类型 | 株数 |
|---|---|
| 花盆（33） | 23.9 |
| 向日葵（1） | 7.7 |
| 卷心菜投手（32） | 8.2 |
| 坚果（3） | 2.6 |
| 豌豆射手（0） | 0.7 |
| 合计 | 43.1 / 45 格 |

- **棋盘是满的**：45 格里 43 株植物，说明不是"没地方种"，是"种下去也打不过"。
- **持续输出只有卷心菜投手一张**：8.2 株/局；豌豆射手几乎不种（0.2–0.7 株/局，屋顶上打不到）；
  咖啡豆（35）在无蘑菇卡组里 **0 次种植**，是死牌。
- 破防僵尸以普通/路障/铁桶的海量消耗为主（L42 晚期 44 只铁桶、45 只普通；L43 另有梯子 20 只），
  没有单一机制型缺口，是**火力总量不够**。
- 阳光全程贴地（决策时中位 25–50），但这不是"买不起"：棋盘已满，是"没有值得买的火力牌"。

## 结果 6：叶值的尺度与视界

- 每局第一个搜索决策的最优叶值均值 0.04–0.09（胜局与败局一样）；
- 全过程中位最优叶值在 `all_plants` 下是 0.612，**真值是 4/32 = 0.125**；
- 死亡前最后一个搜索决策的最优叶值 0.000（终局它知道要输）。

即：**中段系统性乐观、终局才认输**。rollout 视界 2500 tick 只覆盖 2–3 波，
看不到第 25–30 波的崩盘；价值网在"两波之后看着还行"的局面里给高分。
这与 task72 在雾区看到的"最优值尺度"是同一类问题。

## 判断（按 task72b 的顺序）

1. **局面已死？** 否。补全候选后同一批种子能打到第 24–25 波，说明开局与中局都有救。
2. **经济？** 不是主因。棋盘 43/45 满，阳光中位 25–50 是"花完了"，不是"攒不起来"；
   真正的约束是卡组里只有一张持续伤害牌。
3. **叶值尺度/视界？** 是胜负缺口的一半：中段 0.61 vs 真值 0.125，且 h2500 看不到晚期崩盘。
4. **候选？** 是行为层最大缺口、是"老师能不能打屋顶"的前提，但**补全它并不翻盘**。

→ 下一步优先级（主控定）：
   - **① 屋顶卡组**（AGENTS §8 要求先排除卡组×地形）：r7 的咖啡豆是死牌、豌豆射手在屋顶近乎无效，
     等于 7 格卡组只有 5 张可用牌、其中 1 张输出。换掉这两张（如再加一张投手/西瓜）会改变任务语义，
     按 §8 必须新开任务族名并重新登记，历史证据不可直接比。
   - **② 叶值视界/校准**：h2500 → 4000/6000 的敏感性，或直接对中后段局面做终局标签校准。
   - ③ 静态候选网多区重训**不是**当前第一优先：它能把老师从第 4 波救到第 25 波（数据质量意义上的大改善），
     但按本任务的判据（强加候选能否显著翻盘）**不成立**。
