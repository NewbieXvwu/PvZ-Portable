# task58：记忆值多少——最终探针报告（2026-10-24）

## 结论

**记忆有可测的短时信息保留价值；下一轮学生侧受控对照优先考虑ConvGRU，是否接入由主控决定。** 在44个独立测试局上，ConvGRU将雾格占用log-loss从0.141957降到0.133139，AUC从0.8771升到0.8988。它补回无记忆→透视log-loss缺口的6.22%（按局bootstrap 95%区间见下表）。这不是胜率增幅。

短时桶的收益更大：刚被遮住0–120 tick补回76.3%，121–600 tick补回41.1%。三叶草回雾后600 tick内的点估计补回46.4%，但仅4个独立局、8次事件，95%区间跨0，**回雾专项尚不能宣称已确定改善**。总体收益也不足以证明雾区输局主因就是缺少记忆。

占用恢复与开销的综合候选顺序：**ConvGRU、K8、K4、本轮空间SSM实现**。K4可作较低CPU开销的参照；SSM在全体雾格的收益不稳定，暂不优先。类型识别并未同步全面提升，尤其气球类仍弱，见类型表。本实验只完成探针，学生、任务卡组、生产路径和生产开关均未改动。

## 数据与测量边界

164局、66,092个真实决策边界帧；训练/验证/测试100/20/44局，按level/seed分组且不交叉。36局来自task45既有human档案（含诊断去重），另补采128局原dw4i_s1的f8p对局。追加E根与诊断同源，未重复计局；冷启动未留逐帧档案的部分不虚构样本。human表示人类可见的观测模式，并非人工示范。覆盖L31–34，不外推为全部雾关的结论。

每帧公开观测与deploy3引擎重放逐字段一致；PRIV仅用于标签和明确的xray对照。另从原公开档案/公开reset context重编码，414,859,484个float32值逐位一致、0差异。输入沿用v2fog及其原有公开时间/前动作/任务context，不新增追踪或外推特征。标签是引擎在场僵尸落在6×9草坪格的占用与34类型多标签；场外编码列不作为输出格。

五配置各human/xray×3初始化，共30次训练；每次20轮、同样数据/优化器/训练预算，只按验证集雾格占用log-loss选检查点。下表是三个独立初始化指标的均值，逐种子值保存在结果JSON。误差按档案帧计，不逐tick插值。K4/K8为最近决策边界的共享编码堆叠，实际tick跨度不恒定；GRU从原编码读取实际tick差，SSM以实际Δt作连续时间离散化。
