初始划分：每关 memory 种子尾号 0–4 训练、5 验证、6–7 测试，phase-d 独立种子均测试。预期 20/4/12 局。验证和测试含实际三叶草局；样本不足时补采沿用现有学生的 human 对局，保持同源分组，不编写打法或推断标签。标签为引擎在场僵尸在 6×9 草坪格的占用及 34 类型多标签（多只/多类可共格），不含场外编码列。主评估 mask 是引擎 fog_amount>0；可见时刻距今分桶为 0–120、121–600、>600 tick，另列从未见过该格。时间和事件字段仅供评估，不另加特征。

五个配置：当前帧、完整编码的 K4/K8 因果堆叠、格级 ConvGRU、空间对角连续时间 SSM（卷积 B/C、可学习稳定复数模态、ZOH 离散化，实际 tick 差入离散化）。SSM 参考 [ConvSSM 原论文](https://arxiv.org/abs/2310.19694) 与 [S5 作者实现](https://github.com/lindermanlab/S5)，是小型探针实现，不宣称复现论文配置。所有结构目标约同一参数预算，公布实际参数、CPU 单线程 batch=1 单步 p50/p95、状态字节。GRU 读取真实 tick 差，所有结构沿用相同 v2fog 编码；堆叠按决策边界取最近 K 帧，缺失为零，不读取未来。

每配置分别训练 human 与 xray，相同局、标签、优化器、训练次数和验证选模规则；至少三个初始化种子。以未加权二元交叉熵训练占用，并附类型头损失；按验证雾格占用 log-loss 选模，不用测试选模。递归状态每局归零，分块反传时只 detach 不重置。每次 GPU 运行由外层 3600 秒硬超时约束，启动前检查 MemAvailable≥10GiB，记录门禁与实际耗时。

测试报告占用 AUC/log-loss，类型多标签指标；可见时间桶；三叶草回雾事件前后（前窗口用同一批即将回雾的格，防止 mask 人群变化；后窗口另报隐藏格）。事件由实际成功种植三叶草、引擎雾全清、再出现雾确认，窗口 ±600 tick。差距补回率使用 log-loss：`(current_human-memory_human)/(current_human-current_xray)`，AUC 类似；分母无正差距时不解释。按局配对 bootstrap 95% 区间，三种初始化逐种子报告。小样本或区间跨零时写证据不足，不能据此断言雾瓶颈不在记忆。是否进入学生由主控决定。
