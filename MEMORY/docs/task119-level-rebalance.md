## 背景

task117（分支 distillgap，`MEMORY/docs/task117-distill-gap.md`）：r11 训练保留行里 **L7 单关占 61.9%**，8 个蒸馏缺口关（L19/23/24/26/28/29/32/37）合计 4.1%；L32/L37 没有记分板同卡组（磁力菇套）的开局语料。task115：这些关老师 13–16/16，学生明显更低。

## 主控决定

1. **用现有的 K=2 多种子流水线做在役 A/B**，不另开离线实验：每轮两个学生里，一个用现行配方 `recipes/dw4i2.json`，另一个用再平衡配方（新文件，不改旧配方）。由现有挑选面板选一个，再过门禁 v4。轮报告里要记下两个学生各用哪份配方、挑选分数。
2. **再平衡配方**：按关卡给训练行加权（用配方已有的 `source_weight` / `row_weights` / `label_weight` 机制，不新写逐行权重器），把任何单关的有效训练份额压到 ≤ 25%，再按行数反比抬高小关。把加权后每关的有效份额打进训练日志。不改 `wait_keep`。
3. **1.0 倍开局专项**：8 关各加一个固定 1.0 倍、开局决策 0 的采集格（不被自动升倍率），用记分板同卡组。L32/L37 新建磁力菇套任务格（新任务族名，按 AGENTS §8 在 DESIGN.md 登记），原寒冰 / 裂荚 / 示范起点格保留。每格 24 局：12 局 β=0、12 局 β=0.5。种子从 DESIGN 登记的新段取，不与门禁 / 挑选 / 记分板种子重叠。专项占用每轮原有预算，从 L7 份额里让出来，不加整轮时长。
4. 交付 `~/pvz-logs/qc_deploy14g.sh`（台式机，照 deploy14f 的模式：组边界停、代码覆盖、dry-run、首组 rc=0、失败回滚）。**不要执行**，由主控执行。

- 不动台式机 tmux qc；不改历史门禁 / 轮次记录。
