## 反事实与统计口径

审计使用指定的v30续走学生、v3叶子、2500视界、正式CPU mask61和冻结CPU构建。
A比较原动作、同卡同行全部可种格、等待、档案候选均值排序第二项；
B比较原动作、同卡所有行的第0–3列全部可种格、等待。候选去重且逐项验证合法。
每动作64个新未来，各动作严格配对相同seed，不复用老师原来0–11号未来。

报告动作均值、标准误、替代减原动作的配对Student-t区间；同一局面的全部替代做Bonferroni校正，
另报跨600点的BH及依赖稳健BY统计。为避免“挑最好再报损失”的乐观偏差，前32未来选择替代，
后32独立估计有符号价值损失，再按整局bootstrap汇总及按列差/波次分组。
v3分值是本叶子评价尺度，不能当成已经验证的整局胜率差。

原标签老师为v29（原命令见`~/pvz-logs/queue68.sh:18–22`），与本次v30续走不同。
评分后用v29复现原搜索：先2点确认标签/四位小数targets完全相同，才执行全部600点，
记录候选、各候选减半样本数、原策略/挑战者及复核，区分遗漏、剪枝、采样和margin锚定。
随后对v30中显著变差的全部局面，用原v29和另一组独立64未来，只比较已指定的原动作与替代，
