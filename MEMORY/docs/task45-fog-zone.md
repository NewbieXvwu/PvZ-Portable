- 雾区的已知难点见 `MEMORY/docs/student-bottleneck-plan.md` 2026-10-20 00:30 用户答复那条：
  - 雾（`Board::UpdateFog`、`ClearFogAroundPlant`；路灯花半径 4、火炬树桩半径 1 开雾，三叶草吹雾）；
  - 气球僵尸、潜水 / 海豚等新僵尸。
- 用户定了"雾关先实验再定"，问题有两个：
  1. 能不能学会"看不见也往雾里放、种路灯花开雾"；
  2. 不透视比透视差多少。
- 现状：观测只给 `fog` 标志，僵尸列表全给，等于透视。
