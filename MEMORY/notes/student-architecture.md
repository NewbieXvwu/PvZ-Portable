# 学生 / 价值网架构的远期升级：个体 + 注意力（2026-10-26 用户确认要记住）

## 现状

- 学生和价值网的输入：6×10 格子通道（植物种类与血量、僵尸按 80 像素取整），加上标量与任务背景向量（`pvz_value_net.context_vector`：只有出怪倍率和本关僵尸名单，**没有关卡模式标记**）。
- 主干是格子卷积。

## 什么时候会成为瓶颈

凡是要回答“A 和 B 的精确相对位置 / 运动关系”的关卡，格子卷积都吃力：

- **L5 坚果保龄球**：滚动坚果的位置、方向（引擎里的 `STATE_BOWLING_UP/DOWN`）和横向速度。
  - 速度由动画速率决定，每颗坚果在 12–18 之间随机，大坚果 6–10 再乘 2；上下方向固定每刻 2 像素。所以每颗坚果的斜率各不相同。
  - 坚果从第 1 列一路斜滚到第 8 列，会撞上哪只僵尸，取决于跨越整块草坪的空间关系。
  - 按现在的编码，滚动坚果会被记成“出生那一列的一颗坚果（种类 3）”，和普通关站着的坚果混淆。
- **L45 蹦极**：可见落点红靶与蹦极阶段。
- 屋顶投掷类、雾夜可见范围等，也有类似的空间关系问题。

## 方向（按顺序，不跳步）

1. **先补输入，不改架构。**
   - 滚动坚果走独立通道（像子弹一样），带精确位置、方向、横向速度；
   - 任务背景加“关卡模式”标记；
   - 只放玩家在画面上看得到的东西，随机拐弯、随机速率之类还没发生的结果不放。
2. **用记分板量差距**：task103 的 `adventure_scoreboard.py`，在该关比较学生和老师的胜率。差距小就到此为止。
3. **差距大就上个体 + 注意力**：
   - 每颗坚果、每只僵尸、每株植物都作为一个带精确坐标和状态的个体（token），用注意力处理两两关系，可与现有格子通道并存；
   - 需要 GPU 训练，并新开输入版本；旧检查点维度保持不变；
   - 与 DESIGN / 计划 §2 第 9 项“出战学生与续走学生拆开（大模型 / 实体 + 注意力）”是同一件事，合并推进。

## 不做的事

- **不手写轨迹特征**，比如“算出每颗球会经过哪些格子”。这等于把物理公式喂给模型，属于用户明确不要的手写规则或公式。
- 物理推演交给老师搜索用真实引擎做；学生只学老师的选择，价值网学输赢。
