反事实实验：seed 30001 / 第 7 关 / scripted 教师 / 第 266 步
===============================================================

这一份是「规则盖不全败局」的**可复现反例**。它同时证明三件事：

 1. 环境是确定性的（同 seed + 同动作序列 → 逐位相同），所以「那一步换个做法
    会怎样」是**精确可算**的，不是猜的；
 2. 一个被全部机械规则判为「必输」的局，只改**一个格子**就能通关 ——
    而这正是规则清单里自己写明为「盲区」的那一类（种植位置）；
 3. 同一组规则在一败一胜两局上**六条全部同样触发**，只有「哪一路」不同。
    所以它们只能当索引用，不能当败因。

复现命令（脚本在 scripts/，资源目录用 --resource-dir 覆盖）
-----------------------------------------------------------
  # 1) 存档一局（无损：每帧一行，可查任意 tick / 任意路 / 任意一只僵尸）
  python3 scripts/episode_query.py capture --seed 30001 --level 7 \
      --policy scripted --out /tmp/ep30001

  # 2) 看它输在哪（候选信号 + 已知盲区）
  python3 scripts/episode_query.py index --archive /tmp/ep30001

  # 3) 找到「种下第 3 路第一株射手」那一步，枚举全部替代方案（精确重放）
  python3 scripts/episode_query.py whatif --archive /tmp/ep30001 \
      --decision 266 --enumerate --row 3 --save-best /tmp/ep30001_best

  # 4) 复查赢下来的那条时间线
  python3 scripts/episode_query.py lane --archive /tmp/ep30001_best --row 3

机制（不是推理，是数出来的）：第 3 路的火力到底有没有补上
--------------------------------------------------------
「射手·帧」= 每一帧把这一路在场的射手株数加起来。它度量的是**这一路总共
被火力覆盖了多久**，而不是某一帧看起来有几个。

  ep30001          帧数  568   各路射手·帧 0..4 = [1170, 978, 1140, 281, 1038]
                   第266帧之后第3路射手·帧 =   281   结局 第17/30 波 僵尸进屋

  ep30001_best     帧数 1094   各路射手·帧 0..4 = [2707, 1579, 2726, 1689, 3125]
                   第266帧之后第3路射手·帧 =  1689   结局 第30/30 波 通关

第 3 路 281 → 1689，差 6.0 倍。基线那条时间线里，第 266 步种下的 c2 豌豆射手
之后，第 3 路**再也没补过第二株射手**；反事实那条在 tick 21960 补上了第二株
（c2），此后这条路有持续火力。

c2 那株的位置问题是可验证的：僵尸走到它左边之后，它一炮都打不出，
但它在表格里仍然算「1 个火力」—— 于是策略的启发式以为第 3 路已经有人管了。
本轮已把这种情况单独标成 `火力被绕过`（区别于真的一株都没有的 `裸路承压`），
因为两者的应对完全相反：前者要种在**更右边**，后者才是「随便种一株都行」。

诚实标注
--------
· 「第 30/30 波」**不等于**通关：输出里 `种下 土豆雷 @(3,4)` 也是 30/30，
  但 reason 是「僵尸进屋」。要看清 reason 字段，别只看波数。
· 上面的机制解释是**对照两条时间线**得出的，不是受控实验；它说明「差在哪」，
  不证明「只能这么赢」。
· 本轮同时发现「存活崩塌」信号不是败因预言：这条胜局的 1 号路崩塌比 28.3 倍
  （远高于当初 16 局样本得出的 4 倍经验线），照样通关。信号文本已改掉
  「救不回来了」这种因果断言。
