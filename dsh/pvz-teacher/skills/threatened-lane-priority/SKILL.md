# 受威胁路线防御优先级机制（防守资源跨路精准配置）

## 机制描述

在《植物大战僵尸》的多路防守架构中，每一条路线（草坪）的安全性取决于该路现有火力与敌方推进速度、血量之间的动态平衡。
当某条路线出现下列防御真空或严重赤字时：
1. **零火力裸路承压**：该路射手数量为 0，且已有敌方僵尸（如普通、路障僵尸）自屏幕右侧持续逼近；
2. **火力严重赤字且无后手**：该路割草机已被消耗，现有射手 DPS 远低于击杀来犯高血量僵尸集群所需的总伤害量，僵尸将在抵达底线前进屋。

此时，**受威胁路线具有绝对的防御资源调用优先级**。
策略如果忽视该路线的危急态势，而将宝贵的阳光和冷却时间用于：
- 向已有 2 株以上射手、僵尸残血且即将被消灭的**已安全路线重复堆叠火力**；
- 或向无威胁的平静路线继续扩产经济。

这会导致受威胁路线的僵尸长驱直入，迫使策略在僵尸近身时仓促应付（如贴脸裸种脆弱射手或种在僵尸身后盲区），造成植物连续被吃、割草机过早耗尽乃至最终防线崩溃。

## 正确应对规则

1. **跨路威胁评估先行**：每次决定种植火力植物（如豌豆射手）或坚固防御（如坚果墙）时，必须以全盘各路中最迫切需要拦截/歼灭的一路为首选目标。
2. **消灭零火力盲区**：在开局中前期（1–10 波），当某路出现第一只僵尸且该路火力为 0 时，第一笔达到门槛的阳光必须用于在该路建立防守（种植坚果墙阻挡或部署射手），严禁在其他路继续补第二株射手。
3. **无后手路线红线防御**：在中后期（11–30 波），若某路已失去割草机且承压，任何高血量僵尸（如撑杆、路障）逼近时，必须在该路优先前置坚果墙吸收伤害，为后排火力争取充足输出时间。
