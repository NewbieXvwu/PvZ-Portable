# 腹地渗透与高压集群时的范围爆发应急清场机制

## 机制描述

在《植物大战僵尸》中，基础射手类植物（如豌豆射手、寒冰射手、双发射手）均具备严格的**单向右射机制**（只攻击同路位于自身右侧、列坐标大于等于自身的僵尸）。当僵尸突破至防御纵深内部（最前僵尸列坐标深入至 c4 以内，甚至抵达 c0–c2 腹地）：

1. **常规射手失效**：若在僵尸后方（列坐标大于等于最前僵尸）种植射手，射手弹道朝右，对左侧深入的僵尸有效 DPS 为 0；若在僵尸跟前补种，射手缺乏有效输出距离，会被迅速啃食（存活往往不超过 300–600 tick）。
2. **应急范围清场**：当该路割草机已消耗且面临直接突破风险、或密集僵尸群总血量远超单路射手 DPS 承载能力时，必须使用具备 3×3 无死角范围杀伤的即时爆发植物（樱桃炸弹 Cherry Bomb，150☀）在突破集群中心进行定点清场。
3. **策略缺陷**：模型在全盘 878 步中樱桃炸弹使用次数为 0，陷入“僵尸突破入腹地 → 在僵尸身侧/后方机械补种右向射手送死 → 防线崩溃进屋”的死循环。

## 适用与反例边界

- **生效条件**：场上存在密集突破集群或僵尸已绕过防线深入至腹地（x < 360，即 c4 以内），常规射手无法在接触房子前提供足够输出，且场上阳光 ≥ 150 且樱桃炸弹就绪。
- **反例边界（不成立条件）**：
  1. 深入僵尸为单只残血普通僵尸，前方仍有健康坚果墙阻挡或常规射手弹道仍能覆盖击杀；
  2. 阳光不足 150 或樱桃炸弹正处于冷却周期（CD 5000 tick）；
  3. 该路割草机完好待命，波次即将结束且后续无跟进僵尸，可安全依赖割草机保底换取经济与卡片冷却。
